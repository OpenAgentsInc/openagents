---
name: better
description: Push the current task, or a prompt the user gives, to a deeper version of itself. Use only when the user explicitly types /better or $better.
---

I want a deeper version of this task, not a bigger one. Before rewriting it: (1) say what a top professional in this field would do here that I'm not asking for; (2) name the rawest material they would start from instead of what has already been digested for me; (3) name the specific methods and tools they would use; (4) say what, other than you or me, would show the result is right. Then rewrite my prompt to ask for exactly that.

## How to apply it

First decide which case you are in.

**Case A: the user gave you a prompt to improve.** The text with the command is a prompt or task they have not started yet. Give your answers to (1) to (4), then the rewritten prompt. Do not carry the prompt out.

**Case B: work is already in progress.** The command came alone, or with feedback on work you have already done in this conversation ("not good enough", "too shallow"). "This task" is that work, and the feedback is part of the task.

1. Give your answers to (1) to (4) for that task, in a few lines each.
2. Rewrite the task's brief: the original request plus the user's feedback, deepened by your answers.
3. Decide whether to pause. If the new brief changes the goal, widens the scope, or needs a decision, money or access that only the user can give, show it and wait for their go-ahead. Otherwise carry on.
4. Do the work again to the new brief. Start from the raw material in your answer to (2), use the methods and tools in your answer to (3), and before you report, run the check in your answer to (4) and say what it showed.
