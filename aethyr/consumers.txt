# Why each engine module with no product consumer is kept (GitHub #13272; aethyr/README.md, "Layers").
# coax/web/tool.sh layer-check reads this file; coax/web/tool.sh layer-check --consumers lists the modules.
# A module has a product consumer when a file outside aethyr/ that is not a test, tool, example, book
# or document loads it, directly or through another module. A module with none needs a line here:
#   adopt PREFIX #ISSUE     an open issue of the AAA program (#13257) takes it into the product
#   book PREFIX CHAPTER     it is the Metaverse Engine book's own implementation; CHAPTER names it
#   built PREFIX SCRIPT     no file loads it: SCRIPT compiles it by name
#   pipeline PREFIX TOOL    an offline tool that makes a shipped thing loads it
# The longest prefix covers a module. A line that covers nothing now fails: take it out when its
# issue lands the adoption or the module is deleted. A module nobody adopts by the end of the
# program is deleted; git keeps it.
