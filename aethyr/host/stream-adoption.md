# Streaming adoption and remaining adapters

This inventory applies to #12990's bounded corridor profile. Its dynamic
resource contract is shared Coax; browser/native code executes platform
effects and reports observations. The [qualification index](../../docs/verification/aethyr-streaming-12990/README.md)
and [diagnostic/capture record](../../docs/verification/aethyr-streaming-12990/walk-diagnostic-capture.md)
pin the particular builds and receipts. Other realms do not acquire this
qualification automatically.

## Actual shared boundary

| Boundary | Policy and actual consumer |
| --- | --- |
| Source costs and dependencies | `world/resource-cost.coax` and `resource-manifest.coax` derive RCM1 from actual canonical source codecs, including tier layouts, mips, objects and scratch. `resource-admission.coax` wraps existing inbox tickets and renderer resources with seven named lines. |
| Shared ownership | `world/resource-stream.coax` retains concrete dependency owners, borrowers and concurrent staging until completion/retirement. `stream-walk.coax` supplies actual source attempts and fixed-step acceptance. No separate allocator or cell simulator replaces the existing ones. |
| Interest and gameplay | `world/stream-profile.coax` and existing cells separate residency, simulation, drawing, media and prefetch. The consumer uses the semantic query/navigation boundary, stable sleeping actor identity and persistent player/camera/HUD services. |
| Browser source transport | `stream-transport.coax`, HTP1 and `world/stream-walk-transport.coax` bind the original scene, RCM1, whole packed/raw source, exact span and live request key before decode. `coax/web/pack-host.js` prepays actual reader/raw page reservations. Duplicate JS source-hash/entry admission is removed on this carrier. |
| Native effects | `native-backing.coax` binds manifest/device allocation requirements to original leases. The v7 Vulkan carrier plans streamed, staging, fixed-renderer, replacement and readback allocations before allocation, retains owners through actual destruction and records reservations separately from SDK allocation/free observations. |
| Replay and recovery | The canonical state observer and CPU codecs replay accepted histories at every paid tick. Browser and native adapters separately observe actual GPU retirement/replacement and continued movement. Live completion schedules need not produce the same history. |
| Diagnostics | `diagnostic-trace.coax` admits bounded observation storage and marks overflow incomplete without interrupting effect cleanup. `capture-cost.coax` plans actual padded readback, raw copy and logical string temporaries before GPU buffer creation. |

## Memory domains

| Domain | Accounting and limit |
| --- | --- |
| Dynamic fixture resources | RCM1 retained CPU/GPU/object costs and concurrent scratch use a 32,768-byte aggregate with seven category caps. The complete source world costs 62,106 retained model bytes, so the route must stream. These are logical payload/layout costs, distinct from carrier arenas and SDK allocation granularity. |
| Browser transport | Existing 256 MiB/64-ticket storage pool, 64 MiB per allocation; complete reader reactors and separate raw arrays prepay page-rounded extents. HTP1 carrier source/config spans are at most 32 KiB. |
| World and statics | Existing 8 MiB world reservation, initially 2 MiB actual Wasm memory; explicit base/carrier static inventories and measured arena extents are reported separately from payload bytes. The pack master keeps its original 8 MiB reservation after final world disposal. |
| Trace | 1–2,048 records of 24 eight-byte words, with exact array bytes and existing 64 KiB page-rounded reservation. Saturated drop counts identify incomplete histories. Serialized receipt object graphs are observer storage outside the engine trace array. |
| Native backing | Actual Vulkan requirement sizes use the separate measured 2 MiB aggregate/1 MiB allocation profile and named caps. Native serial source reads use a fixed 64 KiB stack window; startup scene/parser/shader windows and reporting stacks are additional fixed host storage, not per-resource retained payload. |
| Capture | The renderer readback grant and shared raw-copy/text reservations precede SDK allocation. A failed encoder zeroes the copy while ownership remains held through completion observation. Returned base64 is explicitly caller-owned diagnostic output. Logical UTF-16 is a declared conservative text model, not measured JS heap representation. |
| Program inputs | Actual world/reader Wasm input extents and hashes are inventoried; mutable byte inputs are zeroed after compilation/identity checks. Retained WGSL code units/logical UTF-16 bytes are reported. Immutable program inputs are distinct from world-resource manifests. |
| SDK, driver and runtime | Compiled modules/pipelines, browser/JS object representation, GC, driver storage and process RSS are unmeasured. Explicit reference zeroing/release never claims immediate physical page return. |

## Named remaining adapters and qualification limits

| Adapter | Retained behavior and scope |
| --- | --- |
| Earlier browser faces without `sw_transport_open` | Keep their published legacy source/span/capture adapter. HTP1 is additive; archived legacy receipts retain their original claims. |
| Earlier HTP1 faces without `sw_trace_open` | Keep observation v1 and its original bounded complete-history qualification. Safe overflow belongs to the new v2 diagnostic profile; the oracle rejects an incomplete v2 history unless explicitly checking only its prefix. |
| Native local-file source adapter | `swn_source` is serial and synchronous, copies through its fixed 64 KiB window, and retains only admitted payload under resource owners. Native HTTP/worker concurrency is not qualified. |
| Native fixed factories | Physical v7 backing is planned for all recorded allocation roles. Factory error-prefix observations cover the named buffer/image/upload roles in their receipts; they do not claim every possible surface/pipeline SDK error, physical OOM or physical device reset. |
| General web realm host | `coax/web/host.js` continues using shared whole-pack/private-crypto transport for other realms. Those realms have no automatic RCM1/HTP1 adoption. Separately compressed range-addressable delivery is #13001. |
| Private or unknown-length pack operations | Preserve the shared loader's existing bounded copy/decrypt/decompress ownership model. They do not claim known-length HTP1 planning or the new per-owner planned transport observation API. |
| Persistent rescue carrier | Browser exact-build whole-reactor rescue retains its separate receipt. HTP1 external transport leases are not restored from a memory snapshot. Native durable rescue remains unqualified. |
| Audio and unused pools | This corridor collects/decodes/retains two PCM sources; audible playback is not qualified. Four streamed actors, one persistent actor and bounded loading/prefetch are declared; unused animation/sensor/effect/dynamic-light pools are zero. |
| Other realm/native adapters | Existing public contracts remain in force. This delivery adopts one actual bounded consumer on browser and native hosts; broader realm migration, mobile hardware and the books' full teaching proofs remain separate work. |
