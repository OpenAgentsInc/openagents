# Canonical SRD spell source data

Source schema 1, SRD 5.2.1. This directory contains **339 spell descriptions**
and **875 entries in the eight base class spell tables**, generated from the
[pinned PDF](../../../../docs/dnd/srd-compliance-ledger.md#source-identity).
No imported record is thereby qualified as executable spell mechanics.

| File | Contract |
| --- | --- |
| `spells.coax` | Canonical textual IDs, names, school, description class mask, source page spans, casting/range/components/duration metadata, full extracted description and higher-level text |
| `class-lists.coax` | Independent class-table rows with level, school, source page and original C/R/M flags |
| `inventory.tsv` | One `spell/<id>` ledger entry per description; mechanics remain `unqualified` |
| `class-lists.tsv` | The same independent class-table inventory using textual spell IDs |
| `discrepancies.tsv` | Nine reviewed differences inside the pinned source, with both values and page references |
| `manifest.txt` | PDF identity, extraction hashes/profile, counts and qualification scope |

TSV files start with a `#` attribution comment, followed by their header.
Generated outputs are checked in. Normal builds need neither the PDF nor Poppler.

## Regenerate and check

Run from the repository root with the checked compiler installed. The import
tool is Coax. The installed native `pdftotext` program (Poppler) only decodes PDF
text; it makes no content, naming, class-list or publication decisions.

```sh
coax/build.sh
coax/web/tool.sh aethyr/rules/srd/import.coax \
  --pdf "$HOME/Desktop/SRD_CC_v5.2.1.pdf" --check aethyr/rules/srd/data
coax/web/tool.sh aethyr/rules/srd/import.coax \
  --pdf "$HOME/Desktop/SRD_CC_v5.2.1.pdf" --out /tmp/new-srd-source
coax/web/tool.sh aethyr/rules/srd/import-check.coax \
  "$HOME/Desktop/SRD_CC_v5.2.1.pdf" aethyr/rules/srd/data
```

`--out` requires a nonexistent destination. All parsing, reconciliation and
generation finish before files are staged in an owned temporary directory and
renamed into the destination. Publication requires the exact PDF hash/size,
339 descriptions, all eight class tables, zero unreviewed reconciliation errors
and exactly nine reviewed differences. `--check` writes no destination files
and fails on any missing or different generated byte. It checks the six generated
files; it does not police unrelated documentation alongside them. A failed write
does not replace an existing catalog. Destination creation is intended for a
single local writer; the filesystem bridge does not provide an adversarial
no-replace rename primitive.

The tool hashes a bounded whole-file read, writes those exact bytes into its
private extraction snapshot and invokes Poppler with argv, never shell text.
Each extraction has a 60-second timeout. Bounds are 400 candidate spells, 2,048
table rows, 20,000 lines per extraction, 2 MiB per extraction/arena/output and the
pinned 6,031,375-byte PDF. Overflow, malformed metadata and unknown table flags
refuse publication. Temporary snapshots and staged outputs are removed on handled
failures; abrupt process termination can leave an owned temporary directory.

The manifest pins the extracted bytes as well as the PDF. The qualification run
used Poppler 26.06.0; a decoder change that changes output must be reviewed and
regenerated deliberately. Do not edit a generated field to make `--check` pass.

## Source text and structured metadata

The source has 339 description headers on pp.107-175. The eight independently
parsed class tables are on pp.28-82. Parser fixtures cover wrapped class headers,
wrapped spell names, singular `Component:`, repeated table headings, page breaks
inside metadata, both source dash glyphs and names containing a school word.

Description text retains Poppler `-raw` content order, line wrapping, line-end
hyphenation, tables and punctuation. Page furniture is removed. Metadata wraps
are joined with spaces. This is a complete extracted text representation, not a
claim of typeset whitespace fidelity or editorially restored prose: PDF text
extraction can merge spaces around styled text. Consult the pinned page when
reviewing mechanics. No language model rewrites or invents source prose.

Casting time, range and duration retain their complete source strings alongside
typed classifications. Explicit single intervals have seconds; action/reaction
timing and special/alternative expressions retain `-1` when a single numerical
interval is inappropriate. Reactions retain their trigger in `cast_text`.
Material descriptions retain cost expressions, per-target costs and consumption
wording without reducing them to a potentially wrong single amount. `cost_text`
is the full material clause when a stated worth or GP amount is present. V/S/M,
ritual and concentration flags are separately queryable. `higher_levels` retains
the source's higher-slot section, while cantrip upgrade text remains in `text`.

Target filters, area geometry, cantrip arithmetic and effect programs still need
mechanical interpretation and independent fixtures in milestones 3/4. Imported
text is never designated narrative just because its mechanics are not implemented.
The current combat tables remain a separate partial executable view; this change
does not replace their behavior or turn imported entries into castable spells.

## Access from Coax

```coax
#load "aethyr/rules/srd/catalog.coax"; // adjust relative to your source
s := srd_source_lookup("polymorph");
i := srd_source_index("polymorph");
on_druid_table := srd_source_in_table(2, i);
```

Class bit order is Bard, Cleric, Druid, Paladin, Ranger, Sorcerer, Warlock,
Wizard. It is deliberately independent of the combat enum. School order is
Abjuration, Conjuration, Divination, Enchantment, Evocation, Illusion, Necromancy,
Transmutation. Numeric spell indices are internal references in this generated
snapshot; persist textual IDs instead. Unknown IDs produce index `-1` or an empty
record. Table membership is source evidence, not effective casting permission:
subclass grants, feats, preparation and world profiles are separate rules.

The current executor's base-class eligibility metadata is reconciled against
these independent class tables with:

```sh
coax/bin/coax test --library aethyr/rules/srd/spell-access-source-checks.coax
```

This checks every executable parent record, preserving helper inheritance and
the legacy `create-water` alias for source `create-or-destroy-water`. It is not
a preparation check or qualification of those spells' effect programs. Runtime
eligibility uses `spell-access.coax`; explicit feature/stat-block/world grants
are creature-local, and ordinary class membership never grants house spells.

## Reviewed source differences

| Entry | Description | Class tables | Preservation policy |
| --- | --- | --- | --- |
| Flaming Sphere | Conjuration, p.132 | Evocation: Druid p.44, Sorcerer p.68, Wizard p.80 | Preserve each school in its own record |
| Mind Spike | Sorcerer, Warlock, Wizard, p.149 | Listed for Warlock p.75 and Wizard p.80; absent from the Sorcerer table | Preserve header mask 224 and table mask 192 |
| Phantasmal Force | Bard, Sorcerer, Wizard, p.151 | Absent from all eight base tables | Preserve header mask 161 and table mask 0 |
| True Strike | Weapon worth 1+ CP, p.171 | No M marker: Bard p.33, Sorcerer p.67, Warlock p.75, Wizard p.79 | Preserve material clause and each original table flag |

These are nine differing source assertions across four spells. The narrowly
scoped `import-policy.coax` allowlist binds ID, field, both values and both page
references; any changed or unknown difference blocks publication. It does not
mark a compiler mutant equivalent or choose an effective gameplay rule. Product
interpretation remains explicit future work. Counts from the base tables are
Bard 129, Cleric 109, Druid 124, Paladin 38, Ranger 48, Sorcerer 138, Warlock 72,
Wizard 217. They exclude subclass/feat grants and house spells.
