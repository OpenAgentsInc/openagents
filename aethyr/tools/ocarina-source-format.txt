Private Ocarina character import

Run aethyr/tools/ocarina-source-pack.coax through coax/web/tool.sh with:
 MODEL_BFRES PACK1_BFRES PACK2_BFRES PACK3_BFRES PACK4_BFRES FACIAL_BFRES OUTPUT_DIR

Inputs are the original decompressed BFRES 10.4 resources. No GLB, JSON,
Python or Blender intermediate is consumed. Licensed source/model bytes stay
outside the repository. CLI errors or failed source assertions publish no pack.
The caller packages the three complete output streams only after a successful run.

link.vertices: 128 bytes per original source vertex, little endian.
 words 0..2 POSITION; 3..5 NORMAL; 6..7 UV0; 8 material index.
 words 9..12: 8 packed u16 joint indices, mapped through the original FSKL palette.
 words 13..14: 8 original UNorm8 weights; unused influences are zeroed.
 words 15..18: tangent XYZW; word19: original packed RGBA8 color0.
 words 20..21 UV1; 22..23 UV2; 24..25 UV3; word26 packed RGBA8 color1.
 words 27..31 reserved zero. This source actually supplies UV0 and UV1 only.
 Rigid vertices are transformed from bone-local to character bind space before
 export; normals and tangents receive the same rigid rotation. Smooth positions
 retain the stored character-space coordinates. All LOD0 source indices remain.

link.indices: little-endian u32, offset to the combined source vertex stream.

link.rig: OCL1, a private format, all integers little-endian u32.
 Header32: magic0x314c434f, version1, joints309, clips8, rigOffset288,
 totalBytes, tracks309, reserved0.
 Clip table: eight 32-byte descriptors beginning at byte32:
  poseOffset, frames, durationF32, speedF32, fpsF32, sourcePack,
  flags, scaleOffset.
  flags bit1 HAS_SCALE, bit2 HAS_BONE_FLAGS; current source clips have flags6.
 Bone records:309*80 bytes at rigOffset:
  parentIndex+1, inverseBind3x4[12]F32 row-major, referenceLocalTQ[7]F32.
 Pose data: frame-major/joint-major TQ[7]F32, translationXYZ, quaternionXYZW.
 Scale data: at scaleOffset, frame-major/joint-major S[3]F32.
 Bone flags:309 original u32 local transform flags immediately after scale data.
 Every record is whole. Table order need not match payload order; payloads must be
 disjoint and together cover all bytes following the bone records.

Clip order and source pack identifiers:
 Wait4, Move_Walk2, Move_Run2, Move_Dash2, Jump_Run_FootL2,
 Land_Run_F_FootL2, BackFlip1, Player_Child_FacialCheck5.
 Integer source frames are sampled, including the terminal frame. The playback
 rate is explicitly assumed to be 30 source frames/second; BFRES does not record
 the engine's actual playback rate. Duration=(frames-1)/30.

Source references and corrections:
 Base layouts: KillzXGaming/BfresLibrary e2c5debca60e9b95e0fd220d32886102d65166bf.
 Extended curve layout: Watertoon/Awn c3c090bb24bc786e6ff94fe3ae68778054f130a9,
 libraries/lib_vp/include/vp/res/res_bfresanimcurve.hpp.
 Modern extended integer point/tangent values are decoded unsigned. Awn's S8/S16
 template labels are not followed for extended quantized key values. Real first
 key values compared to the original per-clip base SRT expose the signed wrap:
 Move_Run signed54 matching channels vs unsigned117, aggregate absolute error
 29.6908 vs0.01809; Land82 vs154, error10.0775 vs0.00635. Separate tangent scales
 and addends bias those unsigned values. Frames of type1 remain signed10.5.
 Both 8-bit and16-bit unsigned endpoint/tangent cases have authored Coax checks.
 Earlier Python/C++ helper agreement inherited signed key assumptions and is not
 an independent pose oracle. Original geometry and inverse binds are unaffected.

Maya segment scale compensation:
 Raw BoneAnim flags bit23 is SSC. The 309-word trailer preserves it per clip.
 Primary older NintendoWare implementation:
 https://github.com/nw4f/G3d/blob/ed43f049896126ec5c32b04f7d9fb38eac37baeb/src/nw/g3d/g3d_SkeletonObj.cpp
 CalcWorldMaya keeps a world matrix U before each bone's own local scale. Root U
 is local RT. For a child, translation is Uparent*(parentLocalScale*localT).
 SSC children use Uparent.linear*localR; other children use
 Uparent.linear*parentLocalScale*localR. After chaining, final world linear is
 U.linear*ownLocalScale. This avoids division by zero. It is an older SDK source
 reference for the same SSC flag, not a recorded Switch2 runtime observation.
 The measured eight imported clips have positive scales; the smallest scale of
 any SSC parent is0.9042605. The tiny1e-9 BackFlip eyelid scale is not such a parent.
