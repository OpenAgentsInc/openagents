# Chat (GPU)

The earlier chat page, drawn on the GPU. [/chat](/chat/index.md) is being rebuilt from nothing (2026-11-11); this page stays until the new one can do what it does.

A direct chat with the OpenAgents agent for general questions. It reads a fresh copy of the public [OpenAgents repository](https://github.com/OpenAgentsInc/openagents) (main) and the web, says which files it read, and can't change anything. Pick Claude Haiku 5.5, Sonnet 5.5 or Opus 5.5 for each conversation. Under Key you can use your own Anthropic API key or Claude subscription token. Theme switches the page between the skins on [/components](/components): Zeron (the default), Everglade, the OpenAgents Metaverse and Terminal. Your browser remembers the one you pick.

Admins only for now. An admin logs in with their Nostr key: `coax/web/api/admin.sh chat` in the OpenAgents repo, or with the OpenAgents phone app at [/login](/login). Anyone else sees only Log in.
