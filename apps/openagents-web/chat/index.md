# Chat

A direct chat with the OpenAgents agent for general questions. It reads a fresh copy of the public [OpenAgents repository](https://github.com/OpenAgentsInc/openagents) (main) and the web, says which files it read, and can't change anything. Pick Claude Haiku 5.5, Sonnet 5.5 or Opus 5.5 for each conversation. Under Key you can use your own Anthropic API key or Claude subscription token.

Admins only for now. An admin logs in with their Nostr key: `coax/web/api/admin.sh chat` in the OpenAgents repo, or with the OpenAgents phone app at [/login](/login). Anyone else sees only Log in.
