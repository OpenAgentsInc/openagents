Coax project · Read or copy the Markdown · Canonical source

The compiler's recorded releases, newest first, including patch releases. Each commit identifies the version's introduction on main; explicitly labelled follow-ups landed while that version was still current. Dates use the repository's America/Chicago calendar.

Reconstructed from the version transitions in src/main.cpp (through 0.13.0) and release.coax (from 0.14.0), reviewed against their changes and retained evidence. The initial reconstruction covers 0.37.0 to 0.1.0 through 99f0d403f2b335654a54e1a60611f8c8251b3776. These are compiler versions, separate from inventory, wire and protocol schema versions. STATUS.md describes current support; RELEASE.md describes the release workflow.

0.38.0 — 2026-10-31

Commit: 0b82a1587a56a4eed8ead255dd32300efe49fc30

0b82a1587a56a4eed8ead255dd32300efe49fc30

- #foreign parameters may be borrowed views of integers, floats and bool ([] u8, [] s16, [] f32, [] bool, ...), passed as the {data, count} struct #export_c uses and declared in the generated header. The host reads and writes the view during the call only: no retention, ownership transfer or asynchronous use; views may overlap and an empty view may have a null data. Views of strings, structs or views, fixed arrays and view results stay E0376.

- The entropy bridge gains cxrand_draw(out, n): one call writes the caller's view; relay_conn.coax and cdp.coax use it instead of n + 1 per-byte calls.
