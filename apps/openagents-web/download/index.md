# Download

OpenAgents for iPhone is in beta on TestFlight. Open
[the TestFlight link](https://testflight.apple.com/join/dvQdns5B) on your
iPhone, install TestFlight if asked, then install OpenAgents.

With the app you can log in to openagents.com by scanning the QR code on
[/login](https://openagents.com/login).
