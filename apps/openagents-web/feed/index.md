# Feed

The read-only NIP-01 kind-1 feed, using the same Coax controller and components
as the iOS app. It opens inside the site's existing app shell. Sign in to read
from your saved relays; use the filter icon for relay, author, time and hashtag.

Implementation and bounds: [Nostr app services](../../../docs/protocol/nostr-app-services-v1.md).
