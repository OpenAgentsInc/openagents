# Invite

An invite to make realms on the Verse. Open the whole link you were sent
(`/invite#code=...`): the page logs you in the way [/login](/login) does,
with an account made on this device if you have none, and uses the code
once. Then MAKE A REALM opens [the realm builder](/realms/new).

When realm making is invite only, an invite is how you get in. The rules:
[docs/auth/2026-10-31-realm-invites-and-auth.md](https://github.com/OpenAgentsInc/openagents/blob/main/docs/auth/2026-10-31-realm-invites-and-auth.md).
