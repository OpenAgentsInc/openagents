# Log in a computer

`openagents login` on a computer shows a link and a QR code to
`/login/device#code=...`. Open it on a device where you are logged in. The
page shows the computer's name. Press APPROVE only for a computer you are
using now: its key then acts as your account. `openagents logout` on that
computer logs it out. A code works once, for ten minutes.

How it works: [docs/cli/2026-11-01-openagents-cli-v1.md](https://github.com/OpenAgentsInc/openagents/blob/main/docs/cli/2026-11-01-openagents-cli-v1.md).
