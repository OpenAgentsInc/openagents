# Log in

Log in to OpenAgents with your email. There is no password.

Type your address and choose SEND CODE. We email you a 6-digit code and a
link. Type the code on the page, or open the link in the same browser. A code
works for 10 minutes and 5 tries. If you open the link in another browser, it
shows the code to type in the window where you asked.

After you log in, the page takes you back to where you came from.
