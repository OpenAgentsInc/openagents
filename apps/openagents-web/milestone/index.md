# First milestone

The first milestone of [The OpenAgents Book](https://github.com/OpenAgentsInc/openagents/tree/main/openagents/book): open login, log in with an emailed code, send a message, receive a reply a part at a time, and stop a reply that is still coming. The iPhone app runs the same shared app.

Every service on this page is a fake with recorded answers. Nothing you type leaves the page, and nobody is logged in. The code the fake accepts is 123456. Each answer arrives half a second after you ask; under a test, only the test releases them.
