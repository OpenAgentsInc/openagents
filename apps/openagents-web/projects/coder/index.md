# Coder

Our coding agents: the router that picks Claude Code, Codex or Microcoder for each message, Microcoder in Coax, and the inference gateways it runs on. Spec: [docs/coder/microcoder.md](https://github.com/OpenAgentsInc/openagents/blob/main/docs/coder/microcoder.md).

The tasks are on Nostr at `wss://relay.openagents.com`; this page is rewritten from them at each release.
