# OpenAgents Desktop

A Mac app in Coax for your coding agents: first a Claude chat that runs on your own Claude Code login, then Claude Code and Codex side by side, talking to each other. Spec: [docs/desktop/coax-desktop.md](https://github.com/OpenAgentsInc/openagents/blob/main/docs/desktop/coax-desktop.md).

The tasks are on Nostr at `wss://relay.openagents.com`; this page is rewritten from them at each release.
