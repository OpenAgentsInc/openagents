The homepage Pylons view is the primary live network view. This standalone board verifies signed provider beacons and counts verified, encrypted answer/status events observed since the tab opened. It retains at most 64 machine rows and de-duplicates 64 work-event IDs per session, freezing the count when full. Those are display bounds for this standalone board, not complete historical job totals. Reload resets observations.

See the canonical quickstart for prerequisites, the join command, authentication, stopping and troubleshooting. Instructions are maintained in one source, docs/connect-a-pylon.md.
