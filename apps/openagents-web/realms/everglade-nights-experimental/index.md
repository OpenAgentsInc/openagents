# Everglade Nights Experimental

An unlisted, independent NWN character creator and small exploration world. This page requires an owner-installed private source pack from a local Neverwinter Nights installation. Original game assets are not distributed with this repository. The public route alone does not supply the scene.

The interface uses NWN’s original Galahad bitmap font, blue-and-gold panels, buttons, menu artwork and twelve-slot quickbar. Choose an actual native character preset, gender, head and outfit. Skin, hair and cloth colors use native palette rows. Enter the world to explore the forest, rural and city sections. Your choice is saved only in this world's browser slot.

- **C / arrows:** character preset; **G / H / O:** gender, head, outfit.
- **J / K / L:** skin, hair, cloth palette.
- **Enter:** explore; **Escape:** close menu or change character; **M:** menu.
- **WASD:** move (run by default); **Shift:** walk; **Space:** jump.
- **Drag:** orbit/look; **wheel:** camera distance. Touch uses the shared movement and look thumbs.
- **1 / 2 / 3:** region; **F:** inspect native animation clips; **R:** resume locomotion animation.

The quickbar’s first six slots select Forest, Rural, City, a native animation, automatic locomotion and Jump. The remaining native slots are empty. Menu and creator buttons accept mouse or touch input. These are the experiment’s controls, not the original NWN combat commands.

This experimental rebuild uses native mesh snapshots for animation and native area/prop textures. It shares engine rendering and controller code with other worlds. Multiplayer, the old spell bar, quests, inventories and dynamic native lighting are not implemented here.
