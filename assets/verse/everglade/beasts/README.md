# Wild Shape beasts

The forms the Grove's druid takes with Wild Shape
([druid demo](../../../../docs/verse/druid-demo.md)). Each is a skinned,
animated model the Everglade pack compiler reads as a form rather than a
static model: glTF with a separate `.bin` buffer, split without other
changes from a committed glb under
[`assets/verse/generated/`](../../generated/PROVENANCE.md) by
`scripts/blender/beasts_admit.py`. `manifest.json` records each file's
digest and the digest of the glb it came from.

| Form | Source | Clips |
| --- | --- | --- |
| `giant_spider` | The Spider from Quaternius's Easy Animated Enemy Pack (January 2019), converted by `scripts/blender/enemy_pack.py` | `idle`, `walk`, `attack`, `jump`, `death` |
| `bear`, `wolf` | Generated by `scripts/blender/animals.py` | `idle`, `walk` |
| `eagle` | Generated by `scripts/blender/animals.py` | `idle`, `flap` |

To readmit after rebuilding a model, run from the repository root:

```sh
python3 scripts/blender/beasts_admit.py
cargo run --release -p verse --example everglade_pack -- assets/verse/everglade
```

then repin the pack (`verse::zones::everglade_pack`).
