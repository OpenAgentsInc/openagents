# Legacy Ruins pack locator

This directory keeps the reviewed zone pack at the path that Coder builds
through 49 download from, when the zone was still called the Atlantis forest.
Its bytes are identical to
[`assets/verse/ruins/`](../ruins/7c1535256a4687e70a0f624f4b97c651bfd0b36ba91347a09041698ef8d246a7.vzp)
(SHA-256 `7c1535256a4687e70a0f624f4b97c651bfd0b36ba91347a09041698ef8d246a7`).
Do not delete or replace it while those builds remain in use. Current builds
fetch from `assets/verse/ruins/`. See [zones](../../../docs/verse/zones.md).
