# Original ritual chamber

The `verse_play` example generates this scene's complete geometry and image pack
from `crates/verse/src/imported/original.rs`. It reads no WoW installation,
MPQ archive, imported model, Classic texture, or Classic font. The JSON timeline
is authored scene data; its `origin_wow` compatibility field is zero.

Run the native scene:

```sh
cargo run -p verse --features imported-desktop --example verse_play
```

After the camera handoff, use WASD and mouse buttons to move and look, and keys
1–0 or the action bar to use the ten abilities. F2 switches to the tactical
controller. Claude starts with 300,000 HP. Cultists respawn 60 simulated seconds
after death. Dialogue and camera cuts come from timed events.

Record the cinematic and controller battle through the native renderer:

```sh
cargo run -p verse --features imported-desktop --example verse_play -- \
  --combat-demo /tmp/verse-original.mp4
```

Recording requires `ffmpeg`. It encodes the renderer's frames without color
grading. The adjacent JSON records actual combat outcomes and the asset pack
revision. Each process generates its pack under its own temporary directory.

## Provenance and boundaries

All chamber, actor, weapon, rig, animation, icon, frame, and particle geometry or
pixels are generated by the Rust code in this repository. These are placeholders
for future appropriately licensed art. The font is the repository's bundled Fira
Mono; its SIL Open Font License is retained at
`crates/verse/assets/FiraMono-LICENSE`. No Blizzard assets are distributed or read
by this entry point.

The shared renderer, director, controls, and existing local combat adapter remain
in their current modules. Generic pack and animation types still have the legacy
`verse-wow` crate name. Gameplay still uses the retained `verse-ruins` adapter;
this milestone does not replace it with a new portable authority service.
Movement currently uses the adapter's bounded floor rather than colliding with
chamber columns. Engine extraction, physical character queries, durable saves,
and multiplayer remain on the engine roadmap and #10406/#10407.
