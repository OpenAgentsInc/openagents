# Fantasy Props MegaKit subset

This retained subset comes from Quaternius's Fantasy Props MegaKit Standard downloaded by the owner. The included `license.txt` declares CC0 1.0. `manifest.json` pins the selected glTF, buffer, texture, and license bytes; runtime compilation verifies them into a private snapshot before importing.

The summoning lair uses torches, lanterns, tables, books, scrolls, candles, a chandelier, cauldrons, cages, chests, barrels, banners, and potions. Rust compiles the meshes and authors their placement, visible flames, liquid, and lighting. No downloaded shader or engine code is used. The current material path reads base color; retained normal and ORM images are source data for future material support.
