# Validated reorganization fixtures

`validated-reorg.json` and `coax/tests/bitcoin/chainreorg_vectors.coax` are
generated by `coax/tests/bitcoin/chainreorg.py --write`, an independent Python
writer/miner. The common 100-block regtest prefix and six branch bodies are
from `lightchain.py`. The extra bodies are B105 (child of the deliberately
invalid B104), A103 and A104. Their SHA-256 hashes are embedded in the JSON.

The live comparison uses the verified official Bitcoin Core 32.1.0 binary
whose provenance is recorded in [validation/SOURCES.md](validation/SOURCES.md).
It compares full regtest UTXO sets, with no peers or wallet, in disposable
private directories. It neither imports a mainnet snapshot nor decides money.
The version, invalid verdicts, state hashes and MuHashes are retained in
`docs/verification/bitcoin-ch60/`. The worked example's exact transcript is
`validated-reorg.out`.
