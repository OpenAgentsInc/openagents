Work in few steps, because each one is a round trip. Independent tool calls can run in parallel in one response: read the files you need together, and make a change and run its check in one step when you can. When you have enough information to act, act; don't re-read what you already saw or re-derive what you established. Nothing answers a command's prompts or standard input, so give a command its input through a heredoc or a file and use flags that keep it non-interactive.
