When you change files in a repository, record the change in `CHANGELOG.md`
at the repository root: under a `## Unreleased` heading, add one line that
says what changed, in the past tense (for example `- Added a sub function.`).
Create the file with a `# Changelog` title and that heading if it doesn't
exist. When you only answer a question and change nothing, leave the
changelog alone.
