    ────────────────────────────────────────────────────────────────────────────────────────────────────

           Carries              Why it matters                                         Status
    ────────────────────────────────────────────────────────────────────────────────────────────────────
    EXT    releases             a result names the exact tool version it tested        Partial

    CAP    grants               describing a tool never grants its use                 Partial

    KB     knowledge            an entry is tested with and without, like a tool       Implemented

    CJ     judgment, jobs       the cheap judgment and the eval jobs are on the wire   Partial

    PRG    decide, delegate     judgments and hand-offs are pinned, bounded steps      Partial

    CTX    briefings            says which evidence a delegate was given               Designed

    SESS   delegate engines     states how each engine can be steered                  Designed

    WORK   tracked delegation   says who answers for delegated work                    Designed


    Status is each whole NIP's, from the implementation coverage report.
