# Chat

The Chat tab is where you talk with OpenAgents. Ask a question, plan some
work, or ask how something in the app works.

- **No computer needed.** Anyone can chat, whether or not a computer is
  connected.
- **Earlier chats** are behind the menu button at the top left.
- **New chat** is the button at the top right.
- **Tap outside the keyboard** to put it away.

When a message needs a computer, such as changing code in a repository,
we offer to send it to Coder. See [Coder](/docs/coder).

## What OpenAgents can't do from the chat

From the chat itself we can't read your files, run code, or reach your
computer. That's Coder's job, and it only happens on a computer you
connected, when you ask.
