# Help

## My phone won't connect

- Make sure OpenAgents is open on the Mac and showing its QR code.
- Scan the code again. Each code works once and only for a short time.
- Try **Can't scan? Copy a code instead** on the Mac.

## Coder won't start on my computer

- Check that the Mac shows it's connected and online.
- Check that you're signed in to Codex or Claude Code on the Mac.
- Check that you picked a project and turned on **Let my phone start
  Coder here** in OpenAgents for Mac.

## Remove a phone

Click **Remove** next to the phone in OpenAgents for Mac.

## Report a problem

In the app, open **Account**, then **Report a problem**, or long-press the
tab bar on any screen. Say what happened and what you expected, and add a
screenshot if you want. You can also send feedback through TestFlight.
