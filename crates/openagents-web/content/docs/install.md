# Install

The [install page](/install) has the download links.

1. **Mac.** Download OpenAgents for Mac 1.0.0-rc.2, open the `.dmg`, and
   drag **OpenAgents** onto **Applications**. It needs macOS 13 or later
   and runs on Apple silicon and Intel.
2. **Terminal.** OpenAgents Terminal 1.0.0-rc.2 installs with one command
   on macOS, Linux, and Windows; the [install page](/install) has it.
3. **Connect a phone.** Open OpenAgents on the Mac and scan its QR code
   with your phone. See [Connect a computer](/docs/connect-a-computer).

The iPhone and Android apps, and OpenAgents for Linux and Windows, are not
published for download: build them from source at
[github.com/OpenAgentsInc/openagents](https://github.com/OpenAgentsInc/openagents).
