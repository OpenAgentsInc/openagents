# OpenAgents for Mac

OpenAgents for Mac is where you chat with OpenAgents on your computer, run
Coder in your projects, and connect your phone to the Mac. It isn't
published for download yet; build it from
[source](https://github.com/OpenAgentsInc/openagents). To use Coder on a
Mac without it, run the one-line install on the [download page](/download).

## The window

- **The sidebar** lists your chats: pinned first, then recent, then
  archived. Drag its edge to resize it. **Cmd+B** hides or shows it.
- **New chat** (Cmd+N) starts a chat at the top of the list.
- **The composer** at the bottom is where you type; the Enter key sends.
- **The footer** opens the **Map**, the **Verse**, **Phones and computers**,
  and **Settings**.

You can search, pin, rename, and archive chats, and a reply can be stopped
and retried. Chats are text only for now: there is no attach button, and a
pasted image is dropped.

## Keyboard shortcuts

| Keys | Does |
| --- | --- |
| Cmd+N | New chat |
| Cmd+F | Search chats |
| Cmd+K | Commands |
| Cmd+, | Settings |
| Cmd+. | Stop receiving the reply |
| Shift+F10 | Chat actions |
| Cmd+B | Show or hide the sidebar |

**Settings → Keyboard shortcuts** lists them. They can't be changed yet.

## Coder on this Mac

When you ask for coding work in a chat, Coder starts right here, in your
project, with the first coding agent that's signed in on this Mac. Its
steps stream into the chat, and when it finishes you can open **What
changed** to see the diff. See [Coder](/docs/coder).

The sidebar shows each coding agent, whether it's signed in, and how much
of its usage window you've used; **Settings → Coder** shows the details.

**Saved sessions** lists the Codex and Claude Code sessions saved on this
Mac. Open one to read it, or choose **Continue with Coder** to hand its
newest part to [Coder](/docs/coder) as a new task.

## Your phone

**Phones and computers** shows the QR code your phone scans, the phones
that can reach this Mac with **Remove** beside each, and Coder's recent
work. See [Connect a computer](/docs/connect-a-computer).

## More pages

- **The Map** shows how OpenAgents routes a message: the router, its
  routes, the answers and knowledge behind them, Coder, the coding agents,
  and the plugins. See [Decks and the Map](/docs/decks).
- **The Verse** shows the Grid, a shared world, live. Choose **Play** to
  walk around in it. See [The Verse](/docs/verse).
- **Decks** open full screen from a chat. See [Decks and the Map](/docs/decks).

## Notifications and updates

When Coder asks a question, finishes, or fails while OpenAgents isn't in
front, a notification names the chat (never the message). Turn them off in
**Settings → Notifications**. When an update is ready, a strip says
**Update ready**; click **Restart to update**.

## Linux and Windows

OpenAgents for Linux and Windows aren't published for download yet; build
them from [source](https://github.com/OpenAgentsInc/openagents). The Verse page isn't available on Windows.
