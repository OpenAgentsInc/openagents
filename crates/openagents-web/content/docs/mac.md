# OpenAgents desktop app

The OpenAgents desktop app, for Mac, Linux, and Windows, is
coming soon. It isn't published for download yet. When it is, it shows on
the [download page](/download).

## Until then

- **Coding work on your computer:** install [Coder](/docs/coder), our
  coding agent for the terminal, from the [download page](/download).
- **Chat in a full-screen terminal:** [OpenAgents Terminal](/docs/terminal)
  comes with Coder.
- **Your phone:** [OpenAgents for iPhone](/docs/iphone) connects to your
  computer. Run `openagents connect invite` on the computer and scan the
  code it shows; see [Connect a computer](/docs/connect-a-computer).
- **Chat in a browser:** [openagents.com](/) works in any browser.

To try the desktop app before it's published, build it from
[source](https://github.com/OpenAgentsInc/openagents/tree/main/apps/openagents).

Next: [OpenAgents for iPhone](/docs/iphone).
