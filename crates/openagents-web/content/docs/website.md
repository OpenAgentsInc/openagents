# Chat on openagents.com

The homepage has a box called **Ask OpenAgents**. Type a question about
OpenAgents and press Enter: the answer streams in from the same OpenAgents
chat the apps use.

## What you can type

- **A question.** Anything about OpenAgents: what it is, how Coder works,
  what a plugin is, what's new in the Gym.
- **`help`** lists what you can type.
- **`download`** (or `install`) links the [download page](/download).
- **`docs`** links these docs.
- **`clear`** empties the box.

The box keeps the last few turns of the conversation, so you can ask a
follow-up.

## What it doesn't do

The website answers questions about OpenAgents. It never starts Coder,
reaches a computer, or opens a screen; for that, use
[OpenAgents for Mac](/docs/mac), [OpenAgents Terminal](/docs/terminal), or
[OpenAgents for iPhone](/docs/iphone).

It answers one question at a time. If you send another before the first
finishes, it says "We're still answering your last question."

## Privacy

The site needs scripts turned on for the box; without them, the download
link still works. It sets one cookie, a random visitor name, so it can tell
your questions apart from other people's. Your questions travel to our chat
service like any other chat; see [Privacy and security](/docs/privacy-and-security).
