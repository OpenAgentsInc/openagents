# Framework contracts

- [View and adapter specification](spec.md): bounded semantic data, typed
  interaction identity, and the responsibilities of a native adapter.
- [Style semantics](styling.md): generic colors, explicit defaults, ordered
  composition, and platform mappings.

The [crate README](../README.md) describes the implemented subset. Application
roadmaps, themes, domain components, and deployment instructions belong to the
applications that consume the library.
