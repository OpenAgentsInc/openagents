# Geist fonts

The Geist and Geist Mono files come from the public MIT Zeron application's
bundled font assets at revision `50cf9e97a32e54a8ea7e1174b80b5adc3b1d2ef4`:
[zeronsh/zeron](https://github.com/zeronsh/zeron/tree/50cf9e97a32e54a8ea7e1174b80b5adc3b1d2ef4/crates/ui/assets/fonts).
The font files use the [SIL Open Font License](Geist-OFL.txt), retained here.
They are unmodified static faces for regular, medium, semibold, and bold text,
with upright and italic variants for both families.

Rust Native's default font pair remains Inter and JetBrains Mono. Applications
can select Geist for a mounted transcript, native field, or semantic theme.
