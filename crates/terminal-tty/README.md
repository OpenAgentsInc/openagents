# terminal-tty

Hook-only ordinary shells for `openagents terminal shell`, with no graphical
runtime. The integrated shell keeps its editor. Requests use the shared typed
chat bridge; the terminal owner admits exact proposals, and a typed result
binds the thread, terminal generation, command, directory, revision, and block.
Ctrl+G shows the warning; Ctrl+Y confirms it. Input or context changes disable
the displayed approval, and uncertain effects never replay input.
