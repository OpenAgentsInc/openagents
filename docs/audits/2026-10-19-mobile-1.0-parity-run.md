# Mobile 1.0.0 parity run: Android and iOS on production accounts

On 2026-10-18 and 2026-10-19 the OpenAgents app for Android and the iOS app
ran side by side against production openagents.com, signed in as dedicated
test accounts, never the owner's. This file records each journey, the
result on each platform, the defects found, and the commits that fixed them.

| Item | Value |
| --- | --- |

| Identity B | A second test identity that the Android release build made on a fresh install with its own key (account `acct_5da6d1ed5f7f68f6`). |

## Also fixed during the run

- Debug builds no longer link an emulator's own key to the shared test
  account on later launches.
- `67ac968f7b`: `openagents-engine` didn't compile on `main` (the device
  origin read a `config` that wasn't in scope), which also broke the desktop
  app build and Design Lab's desktop capture.

## Not covered

- Push notifications (no FCM configuration in these builds; iOS push stays
  off), voice calls, and physical devices. These are owner steps.
- iOS joining from an invitation link: the simulator build has no associated
  domains, so the link opens Safari. The shared Rust fix covers both phones.
