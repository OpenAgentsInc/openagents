# Bitcoin

This directory holds surveys and plans for OpenAgents' own Bitcoin and
Lightning infrastructure. The current wallet code lives in `crates/wallet`;
its usage is in [the CLI guide](../cli/README.md).

- [Bitcoin and Lightning node history](2026-09-28-bitcoin-node-history.md):
  every node OpenAgents has run, the code and runbooks that remain, and the
  options for running a node again.
