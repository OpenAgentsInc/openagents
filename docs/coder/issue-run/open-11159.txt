sess_ bearer no longer go to the upstream server. The fix adds /coder/ to OWNED_PREFIXES in upstream.rs.

them.

and checks that each one is owned. It skips tests.rs files, which set up stand-in servers. It also skips two
paths that are meant to go upstream: /api/v1/ (the inference API) and /u/ profiles, which an existing test
already expects to be forwarded. Routes registered through a constant rather than a written-out path aren't
scanned, so the test doesn't cover those. The new test and the existing ownership tests pass, and fmt is
clean.
