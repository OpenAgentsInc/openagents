# Portable host packaging evidence

The [runtime guide](../../runtime/portable-host.md) defines this bounded M11
slice. All work used synthetic source and temporary state. No model request,
production deployment, existing service change, or benchmark run was involved.

| Platform | Observed result | Limit |
| --- | --- | --- |
| macOS launchd | Real Coder task owner started from the upgraded bundle and then the rolled-back bundle. Both finished, produced one expected line, and refused repeat execution after an explicit service restart. | One developer Mac, two byte variants of a public uncommitted build; not a clean-host or cross-release migration result. |
| Linux systemd | Unit verification and an actual one-shot shell fixture passed; duplicate start while active left one invocation. The temporary service was stopped and unlinked. | Service plumbing only. Installed Coder lacks the new task interface, and NixOS lacks `/usr/bin/git`; no Rust task-owner Linux success is claimed. |
| Installation fixtures | Nine tests passed, including failed upgrades, insufficient space, incompatible state, interruption, duplicates, changed bytes, locks, and preservation on uninstall. | Synthetic local storage and failure injection, not a physical power-loss experiment. |

The [macOS receipt](macos/receipt.json) records 285 ms and 317 ms for the two
bounded child processes. These are single observations, not throughput or
latency benchmarks. Commercial/model charges were absent; total host and
operator cost remains unknown. Both unique launchd services were booted out.

The first runtime attempts exposed two fixture mistakes: command and task IDs
must differ, and a write-granted task must use a linked worktree rather than an
ordinary repository whose `.git` overlaps the protected path. The owner refused
both before an effect. The successful retained fixture uses distinct IDs and a
linked worktree. Earlier failed attempts are not counted as passing runtime
acceptance.

Files include:

- [macOS receipt](macos/receipt.json), original launchd definitions, exact
  [task journal](macos/tasks/tasks.json), full ATIF traces, artifact manifests,
  and retained result bytes under `macos/tasks/`.
- [Linux receipt](linux/receipt.json) and the exact verified systemd unit beside
  it. The shell fixture is generated by the checked-in acceptance script.
- [Infrastructure test log](tests.log), [macOS log](macos-runtime.log), and
  [Linux log](linux-runtime.log).
- [File manifest](manifest.json), with SHA-256 and byte length for every
  retained file.

Absolute temporary paths are historical evidence, not paths a reader should
execute. The runtime guide provides reproducible commands that create fresh
local artifacts. The helper records the supplied source revision separately
from the installed binary's actual version response; neither is a remote build
attestation.
