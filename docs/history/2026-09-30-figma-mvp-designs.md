# Figma MVP designs: table of contents

**This document records history.** It indexes the 2024-era OpenAgents chat MVP
design files in the OpenAgents Figma team. Those designs show the agent-store
chat product, with ChatGPT-style chat, paid upgrades, and later login through
X. They do not describe the current apps. For current direction, see the
[master roadmap](../roadmap.md).

The files are private to the OpenAgents Figma team, so the links open only
for team members. Every screen links directly to its frame. Section node IDs
are given in code so an agent can fetch a render or design context for any
entry.

Surveyed 2026-09-30 from the Figma REST API. The index below was generated
from each file's node tree, so it lists every named top-level frame in every
section.

The counts separate four kinds of frame:

- **Designs** are OpenAgents screens.
- **Proofs** are screenshots of the built app placed next to the design.
  Their names contain `Proof`.
- **References** are `ChatGPT - …` or `TypingMind - …` screenshots that a
  design was modelled on.
- **Study** frames are competitor screenshots on the Design Study page.

These files also belong to the team folder
`https://www.figma.com/files/team/1351612917968170522/folder/215723953`.
The folder may hold more files. Listing it needs a token with the
`projects:read` scope.

## Design summary

- **Look.** Near-black background with a monospace typeface throughout. The
  palette is greys plus four accents: green for success, red for danger,
  amber for Bitcoin, and white for brand. Primary buttons are white with
  black text. Desktop frames are 1280×832 and mobile frames are 393×852.
- **Layout.** A 256px sidebar with Chats and Agents tabs, and Blog, Changelog,
  and Developer docs links. A navbar that picks the model or agent, with share
  and account controls. A message column 768px wide, and a composer that notes
  "Chat agents make mistakes. All chats are public."
- **MVP-v1.** A ChatGPT-like chat with a model picker, and email and password
  auth: sign up, create password, verify email, login, and reset password.
  It adds sign-up limits and a Stripe checkout for a $10-per-month
  "OpenAgents Pro Membership", plus a share flow. Its Research pages hold a
  study of Gemini, Mistral, TypingMind, You, Chatbot UI, Poe, PPQ, and
  ChatGPT, and a mood board.
- **MVP-v2.** Adds agents: new, edit, and delete an agent; change, explore,
  and select agents; and the Agent Store (Chat Agents plus LLMs). The plan
  becomes an "Explorer" upgrade. Each flow gets a Proofs section of
  screenshots from the built app, including mobile. Auth Update revises the
  email flows.
- **MVP-v3 and v4.** Auth is login through X only: a "Join OpenAgents" modal,
  then Login with X. Signed-out users land on "Who would you like to speak
  with today?", which shows the Agent Store. Chat flows are split into First
  Chat, New Chat, Change Agent, Rename Chat, and Delete Chat. Upgrade flows
  are split into Sign Up Warning, Upgrade Warning, and Upgraded Wait. Every
  flow has a desktop row and a mobile row, and most have a matching `- Proof`
  section.
