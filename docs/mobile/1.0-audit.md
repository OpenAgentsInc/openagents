# OpenAgents mobile 1.0 audit

Date: 2026-10-09. Scope: the OpenAgents phone app (`crates/openagents-mobile`,
the iOS host `bins/openagents-ios`, the Android host `bins/openagents-android`)
and `crates/coder-mobile`, which ships inside it as the Verse tab's world.
Checked in code and tests (`cargo test --manifest-path
crates/openagents-mobile/Cargo.toml`) and by running the app in the iOS
simulator (screens in
[`bins/openagents-ios/verification/2026-10-09-streamlined`](../../bins/openagents-ios/verification/2026-10-09-streamlined/)).
A preview build (`OPENAGENTS_MOBILE_PREVIEW=on`) was also run: the Verse tab
opens on the Grid at the Gym, and Account shows Trainer, Train Coder,
Profile, Playtest, and Tailnet; the normal build shows none of them.

**Rule:** what works end to end today stays; what does not is hidden behind
one compile-time release gate, `OPENAGENTS_MOBILE_PREVIEW`, without deleting
its code.

## The release gate

- `OPENAGENTS_MOBILE_PREVIEW=on` in the environment of the Rust build turns
  the preview features on. Unset (or `off`), every build hides them: release
  archives, Play bundles, and normal simulator and emulator debug builds.
  Rust reads it once, at compile time (`crates/openagents-mobile/src/preview.rs`,
  `preview::ON`); the iOS host asks `openagents_mobile_preview()` and the
  Android host `OpenAgentsNative.preview()`, so the hosts and Rust always agree.
- Re-enable for development:
  `OPENAGENTS_MOBILE_PREVIEW=on bins/openagents-ios/build.sh sim`, or
  `OPENAGENTS_MOBILE_PREVIEW=on bins/openagents-android/build.sh run`.
  Cargo rebuilds the library when the variable changes.
- Hidden means no entry point: no tab, Account row, starter chip, routed chip
  under a reply, Gym card, deep link (`playtest`, `verse_gym`, Train Coder's
  `chat`), or developer launch argument (`--tab verse`, `--account-route
  trainer|tailnet|playtest|reports`, `--gym-first-run`, `--gym-script`) shows
  any of them. A phone that opted into the Gym on an earlier build opens on
  the plain chat.
- **Playtest logging** follows the gate: off unless the build is a preview
  build or was made with `OPENAGENTS_PLAYTEST_LOGGING=on`.
  `OPENAGENTS_PLAYTEST_LOGGING=off` still forces it off. A build with logging
  off records nothing and deletes any log an earlier build kept.

**Shell (#11126, the build after 54):** the iOS app has no tab bar. A top
bar holds the menu, the **Coder** / **Verse** switch on a new chat and in
the Verse, and **New chat** in a conversation; the menu opens a drawer with
Coder, Computers, Wallet, the Verse, Settings (formerly Account), recent
chats, and search. **Coder** is the one conversation: a new chat shows four
feature cards with **Try it** in place of the starter chips (they open on a
different card each time and move on by themselves, pausing under a finger
and never with Reduce Motion), and the network decides when a message needs
Coder on a computer. **Verse** is the plain Grid. **Explore the Verse**'s
Try it opens it, and a reply the answer bank's `meta.verse` serves carries a
typed `verse` offer that shows as an **Enter the Grid** card. Report a problem moved from a long press on the tab bar to a
long press on the menu button. The Android app has the same shell from the
same Rust state (`Shell.kt`). On both, a reply that names web links shows a
card for each under it (the page's title, its site, and its preview picture
when the page has one, read by the app within size and time limits; a plain
link card otherwise), and the composer floats over the conversation, which
scrolls under it.

Other agents' work this audit leaves alone: the six sample plugins are being
removed from every surface, and phone account sign-in with full sync is being
added; their entry points are not part of the gate.
