# Task index research

Verified procedural memory for repository coding agents: a strong model turns understanding of a repository into reusable task recipes, and a cheaper model uses them to make complete changes.

- [task-index-research.md](task-index-research.md): 25 papers in six avenues, and the experiments to run first.
- [papers.md](papers.md): the papers with arXiv links. `./fetch.sh` downloads the PDFs into `papers/` (kept out of git; arXiv papers aren't ours to redistribute).
