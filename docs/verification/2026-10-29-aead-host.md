# Experimental AEAD host bridge

**Update:** The subsequent [inner-workspace integration](2026-10-29-aead-inner-workspaces.md) supersedes this snapshot’s statements about the AEAD cipher and MAC still using the older entry points. Its remaining erasure and production limits still apply.

The internal host bridge connects the Coax seven-region numeric admission,
caller-owned AEAD workspace and cleanup/publication state. The host observes
pointers, executes synchronous cipher calls and performs observable wipes;
Coax decides admission, authentication, cleanup order and publication.
A caller provides a zero-initialized aligned host and distinct, live, accessible,
stable workspace, key, nonce, AAD, input and output. Calls are serialized and
non-reentrant. The caller is responsible for nonce uniqueness and for erasing
its own key, input and any published output when appropriate.

The host checks actual host/workspace extents, target-width address ranges and
all seven pairwise aliases before cipher effects. It cannot prove allocation
size, permission, liveness, Wasm linear-memory extent, absence of concurrent
writers or truthful erasure. Early refusal leaves pre-existing workspace bytes
untouched. A failed start, including a bad tag, may leave cleanup pending; the
caller must inspect status and complete it. Work and staged output are erased
before their cleanup acknowledgments. Closing an unpublished success first
cancels it and requires a staged wipe.

On successful publication the host copies the result and then erases its
staged copy. If that wipe fails, status 2 explicitly means the caller's output
may contain sensitive data, including when a further output wipe attempt also
fails. The caller must quarantine and erase it; closing still attempts to wipe
the host. The test-only effect hook simulates this condition, not a claim that
the real eraser naturally fails. Input and output copies outside registered
buffers, lower-level cipher/MAC stack temporaries, registers, crashes, OS
snapshots and physical-device behavior remain unproved. This is not app/key
custody integration or production-secret approval.

Checked/release native ASan/UBSan, actual Wasm and iOS 26.5 Simulator run the
draft AEAD vector, all sixteen tag-byte failures, first ciphertext/nonce/AAD
byte failures, cancellation and abandoned success, output/workspace alias and wrap
refusals, a misaligned host, guard bytes and actual registered-region wipes.
Test-only injected effects cover workspace/stage retry and publication errors
with both successful and failed attempted output wipes. These are finite
position cases and cooperative calls, not arbitrary concurrency, crash recovery
or hidden-copy erasure. Python/Node are local test tools only.
