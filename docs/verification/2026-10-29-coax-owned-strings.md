# Owned interpreted string snapshots

A check that casts the same 32 KiB byte array 4,096 times executed 98,312 interpreter steps before and after this change. On this host, `/usr/bin/time -l` reported maximum RSS of 139,673,600 bytes with the 0.19.0 compiler and 5,308,416 bytes with the ownership prototype. Input SHA-256: `815fb913d52fc7d3985943d3837bf34f0fabbd7621eabcf8fda3cbd5417b44c3`. Compiler hashes were `5d9239a19f3567bf6691c0db034124ead36952885d2fb08bfb5627425fc190ce` and `9739e1f21adad0ec7fb9d09c82a590994faa1d8e075d040b2783f35c37359a41`; the latter was a stage-zero prototype reporting the prior release metadata. RSS is an allocator- and host-dependent observation, not a guarantee or a bound on the compiler process.

The prototype passed all 20 checks in the unchanged Nostr JSON graph and all 177 checks in the frozen event snapshot `f5581bacd14ca501ab667e6bb25322e7c31bf837` (event root SHA-256 `45118f2a7a9b5dc19466099fd0553ab1529de6cf768e16ce70a59df27e88e4d2`). That event snapshot's mutation gate had 13 survivors and is independently being revised; this compatibility result does not close it.

The sanitizer harness exercises repeated snapshots, aliased/sliced ownership, frozen values, exact live-byte and materialization-work limits, rollback after an injected allocation failure, and a real exhausted aggregate allocation during freezing. The latter exposed a partial syntax rewrite in the previous implementation; the fix prepares the frozen value before changing the expression and restores field-default state on failure. Language-level checks exercise frozen scalar and aggregate results, field defaults, returned strings and aliases in both native profiles. The existing Coax aggregate limits and step budgets are unchanged. The string limits cover owned cast snapshots, including one terminator per allocation; literals, ASTs, metadata, unrelated host allocations and total RSS remain outside their scope. Cyclic aggregates can retain snapshots until file teardown. The mutation scheduler still falls back on any graph with a string cast.

After the transactional freeze fix, the 0.20.0 stage-zero compiler (`768f0b94c62e4d4b43550944e61245f417ff3951109a23a6bc2dd6f9367fd743`) passed all 20 unchanged JSON checks and all 180 checks in the event team's explicitly frozen revision (root SHA-256 `ee3b610f68ecfaf16458e296ed63d8ca50ce32f5b8eb1f6ad7215c369d7e94c3`; 22-file manifest retained by that team). All ten scheduler reference-comparison tests also passed. The revised event mutation and full admission remain separate gates.

An independent read-only source review examined escaped string views, aggregate cloning and assignment, frozen scalar and aggregate roots, owner/admission cleanup, default-state recovery and the unchanged scheduler fallback. It found no lifetime or partial-expression rewrite blocker in the reviewed implementation. Earlier successfully frozen fields are not rolled back as one batch if a later field fails; this work does not claim transactionality across an entire struct's defaults. The review does not establish a complete compiler resource sandbox.

The reviewed source hashes were `2f24cddfffd9b6fc5f0d53c0e9f0a8aaadd1d7a8e44b2f215ea3963233146553` (`coax.h`), `7ef39dd45026e49ec1bc4a971803f3386b9fb845566128dc36f45795b6961cb2` (`eval.cpp`), and `cc83c7ffdd5b5577bd93c766e810958dc1156b2ef3dc09ec968954a8639a7eeb` (the checked budget policy). The reviewer also identified a test-harness allocation/deallocation portability mismatch; the harness now pairs the injected array allocation with matching deallocation, and the focused sanitizer tests pass.

The final Python-free 0.20.0 bootstrap binary (`b40b48824cd587d6188540c89a7827305869d3cf239c462be6f36346b810f5b3`) passed the revised frozen event graph's 180 checks. The affected resource (12), scheduling (10), and verifier (17) test suites passed on that binary. No source-audit or production-cryptography conclusion follows from these compatibility tests.

The final binary passed the five dedicated string tests, including the ASan/UBSan owner harness and actual check-level limit refusals. The OpenAgents iOS Simulator Debug build also completed successfully with the changed compiler on base `17c2656677d168bb4a0d037608dc425b7e531aad`; the later main change to that app only increments the build number. This is a build check, not a device run or a TestFlight deployment.
