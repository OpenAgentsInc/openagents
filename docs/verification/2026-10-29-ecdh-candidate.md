This candidate computes the 32-byte affine x coordinate after a public x-only peer lift and strict scalar admission. It does not use libsecp256k1's default ECDH hash callback. The test harness derives NIP-44 conversation keys independently by HMAC-SHA-256 over that raw x with the `nip44-v2` salt; the candidate itself returns raw x and does not implement the NIP-44 key schedule.

The full byte-view entry checks public lengths and lifts the public peer before reading scalar bytes. It computes a 0/1 validity mask for scalars in 1..n-1, substitutes one for invalid inputs, runs a fixed-schedule multiplication, and masks staged bytes on scalar refusal. Its private arithmetic uses the 8×32 group formulas and an inverse with the existing public exponent schedule. The immutable schedule is validated by a compile-time assertion. The fused field reduction selects a single `+c` candidate for either an incoming carry or a canonical subtraction, where c=2^32+977. The recorded integer lemmas, SAT negative control and independent source review are conditional on the source correspondence, field bounds, canonical group closure, finite public lift and subgroup premises; they do not authenticate emitted machine code. The schoolbook loop induction and unrolled fold word-level bounds rely on the previously reviewed #3653 source and lemmas rather than being newly established by this proof script.

These are distinct observed refusals; neither establishes acceptance. These refusals remain recorded, and no accepted result is claimed for the complete byte-view path. Whether the caller actually supplies a public peer is a caller premise.

The platform wrapper accepts only truthful, live, disjoint input/output/workspace regions with an aligned caller-owned workspace. It calls the Coax admission policy before arithmetic. A successful result is copied to output while the caller keeps it private; the wrapper then uses the identified-buffer erasure effect on the whole workspace before returning success. Scalar and peer errors leave output unchanged and wipe admitted workspace. On an erasure failure it reports cleanup pending, attempts to erase any staged output, and requires the caller to retain the exact original work and output pointers privately and retry cleanup before reuse. Retry is stateless and depends on truthful ownership, unchanged pointers/lifetimes and serialized calls; it does not bind a retry cryptographically. Invalid metadata refuses before workspace ownership is admitted. The effect does not erase hidden compiler, register, ABI or other copies; this is not production-secret erasure approval.
