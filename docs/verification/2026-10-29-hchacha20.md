# HChaCha20 primitive, initial evidence

This derives a 32-byte subkey for a 16-byte nonce; it is not XChaCha20,
Poly1305, an authenticated cipher, or a complete NIP-49 backup. It is not
approved for production secrets. Its internal ABI relies on valid views and
a truthful overlap observation. Temporary values do not establish secure
erasure, and source checks do not establish target side-channel behavior.

The implementation reuses the existing ChaCha block rounds and removes their
feed-forward using wrapping subtraction before selecting the specified words.
The test in section 2.2.1 of the [XChaCha Internet-Draft](https://datatracker.ietf.org/doc/html/draft-irtf-cfrg-xchacha-03#section-2.2.1)
passes. All 378 mutants in the loaded graph were killed. The independent
round-state model in `coax/tests/nostr/hchacha20.py` checked 1,002 cases per
checked and release profile in native and emitted Wasm. Both profiles also
passed native ASan/UBSan boundary checks and compiled for arm64 iOS Simulator;
no iOS execution or physical-device result is claimed.

The run used coax0 0.22.0 (`9857663bf2c87462d9acdd09b118c9a3e298a3a9caa43ab842dfeabedcce0cd7`)
and source `03a5afd94d3c57bd3df0aeb89c218bc5813c2cf328fe642c1d346cc17b938537`.

`dd5b47d8b0d465f4c7bbed2955d46266e0cf73d99c091b2047ab6b640c9634f0` and
`8aa0d2d18cc0f90db4238a6dd523049515182ed606cdfe4a5886cdbbe518f085`;
release values were `2000a5ef35fb5a32d58ca6e060d8c1c0acec07d563c225f6f3ba577852d6c33e`
and `34f4bb40a9225c8007238f0e0be6fb5bb774e6e2862bfd158214e9cd61b8069e`.
The run used arm64 macOS, Homebrew clang 23.1.4, Node 26.12.1, and iOS
Simulator SDK 26.5.
An independent source review found no concrete arithmetic or admission defect
in this scope; it did not review target timing, erasure or production use.
