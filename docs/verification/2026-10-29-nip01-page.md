# openagents.com/nip/01, 2026-10-29

The page (`apps/openagents-web/nip01.coax`, task #eb7a `nip01-page`) runs one
captured relay event and four copies of it, each changed in one place, through
the shared Coax event reader and BIP-340 verifier, and draws where each stops.
The verifier (`nip01-verify.coax`) is its own Wasm library: the reader's and
crypto's flat names clash with the renderer's. Its result is the only thing
the page draws a verdict from; the page grants nothing.

The event is the 681-byte repository announcement from
`coax/lib/nostr/fixtures/coax_relay.coax` (object SHA-256
`dcf32812f99618c23fa3dd2bff0569ef590f2b15d2d44b61bfb61f3257f00e93`, id
`813d9fb0…bc9d21`), and the copies are the `.dev/nostr` probe's: id digit,
content letter, signature bit and kind 99999. Verification is
`nostr_event_read` (id recomputed from the NIP-01 preimage) then
`nostr_fast_verify_vartime`, as `store_admit.coax` does.

## Results (Linux x86-64, compiler built from this tree)

- `coax test apps/openagents-web/nip01.coax`: 46/46, including frames inside
  the vertex budget at 1440x900@1, 390x844@3 and 768x1024@2 in both views.
- `coax test apps/openagents-web/nip01-verify-test.coax --steps 1000000000`:
  220/220. REAL verifies; ID and TEXT stop at NE_ID with the claimed and
  computed ids differing as expected; SIG stops at NE_SIGNATURE; KIND at
  NE_SHAPE. These checks verify real signatures, so they need more than the
  default 20M steps; they are kept out of the library so its build runs none.
- `node coax/web/tests/nip01_wasm.cjs apps/openagents-web/build/nip01.wasm`:
  74 frames, 7 keys, 18 hotbar clicks across desktop, phone and 2x, every
  case's verifier result checked in Wasm, guard bytes intact.
- `coax/web/check-visuals.sh apps/openagents-web`: passes.

The Wasm was built on Linux with `coax/web/toolchain.sh`'s nixpkgs toolchain.
A toolchain set up from scratch produced the same 124,247-byte module.
