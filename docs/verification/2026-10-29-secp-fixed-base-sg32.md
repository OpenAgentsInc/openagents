# Fixed-base source revalidation with canonical 8×32 group arithmetic

**Source-audit security correction:** the historical aggregate `accepted=true`
reports described below are superseded and untrusted pending exact-graph
revalidation with the corrected analyzer. See the
[checked-cast advisory](2026-10-29-secret-audit-checked-cast.md). The
separately recorded arithmetic and timing observations retain their stated
scope and do not depend on that source-audit acceptance.

The fixed comb retains its actual compile-time `SgPoint` tables, public profile parameters and full-table masked selector. Each selected canonical point is converted to `Sg32`; online doubling and addition use the reviewed total 8×32 group kernel, and the canonical result converts back to the existing `SgPoint` ABI. Table generation remains the existing public Coax computation. The selector is private by convention and requires canonical valid generated entries; the real wrappers supply the reviewed tables. This is source-scope and public arithmetic evidence, not object/JIT timing, erasure or production-secret approval.

The checked native-library source audit analyzes each actual wrapper with the explicit 250,000,000-step compile-time table budget, without changing source-audit limits. Both raw reports have `accepted=true`, no guard obligations, 30 reached procedures and 46,115 visits. They bind the actual ordered source graph and compiler-recorded source hashes; generated `#run` values are treated as opaque public data only after the trusted driver verifies successful compilation of that graph. The [evidence](2026-10-29-secp-fixed-base-sg32.json) records the compiler, profile, inputs and both reports. The source audit does not establish target-code timing or production-secret safety.

Both real tables were compiled and independently compared entry by entry: 768 comparisons across checked/release modes, 517 boundary scalars for each profile and mode, and 100,000 deterministic random scalars per profile and mode in native. Wasm checked and release each tested 100,517 scalars against both profiles, using a 1 MiB stack. The native and Wasm comparisons had zero failures; sanitizer and short-input refusal checks also passed. Native canonicality in the large stream run is checked on canonical wire output, while table, boundary and Wasm checks inspect raw limb bounds. The actual page/native tables are 30,720/61,440 bytes. Each combined checked/release compiler invocation used 166,665,151 evaluator steps under the explicit 250,000,000 cap. The recorded aggregate peaks, 38,385 slots and 7,266 containers, are frontend-evaluation peaks sampled before authority checks, not peaks for the whole invocation.

For this native arm64 `-O2` build the web and native wrapper frames were 30,800 and 61,520 bytes; `smb_comb` used 1,792 checked and 1,808 release bytes, in addition to nested calls. Generated C was 408,620 checked and 407,774 release bytes; objects were 154,560 and 149,728 bytes. Wasm's explicit stack and these native frames are test-build observations, not proof that every host is provisioned correctly.

All 88 base and 91 checks per wrapper passed. The complete wrapper checks consumed 8,781,857 web and 10,237,446 native evaluator steps under the unchanged per-check limit. Full mutation killed 1,486/1,486 base, 1,491/1,491 web and 1,491/1,491 native mutants with no waivers. The test-only evaluator still uses explicit 250,000,000 steps for actual table construction; this is separate from source audit and check budgets.

An independent read-only source review found no concrete blocker under the private generated-table and fixed-wrapper preconditions. It traced canonical generator/table closure, complete-mask full-scan selection, 26/22-bit to 8×32 conversion, total group closure, infinity, and public loop/index schedules. It relies on the existing #3653 arithmetic evidence; arbitrary table, width or spacing inputs are not admitted by that review. The reviewer did not rerun the checks or approve target timing, erasure or production use.

The release native timing probe used one million samples per fixture: web t=0.108, native t=-0.934, fixed control t=1.415, and planted branch control t=-377.107, which was detected. Fixed-base oracle and mutation runs and other shared-host work overlapped collection, and fast controls had many zero clock ticks; long-tail scheduling noise limits sensitivity. This is a declared-profile observation, not proof of target constant time.
