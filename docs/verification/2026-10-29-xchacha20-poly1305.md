# XChaCha20-Poly1305 composition, initial evidence

This experimental bounded AEAD accepts up to 1,024 bytes of associated data
and 4,096 bytes of plaintext, sufficient for the NIP-49 framing but not the
whole backup implementation. Callers must ensure a unique nonce for each key
and supply stable input buffers, valid views and a truthful aggregate overlap
observation throughout each call. Key and
plaintext temporaries are not proven erased. Target timing, public pointer
admission, key custody and production-secret use remain unapproved.

Sealing stages ciphertext and tag before committing output. Opening verifies
the tag before writing plaintext. The published XChaCha20-Poly1305 draft
vector passes, and all 697 mutants in the loaded graph were killed. The
independent HChaCha model and OpenSSL ChaCha20-Poly1305 checked 132 inputs per
native and Wasm checked/release profile, including empty and maximum inputs;
all 16 tag-byte mutations and ciphertext changes were refused on both. Native
checks also reject altered nonces and associated data without writing output.
Native ASan/UBSan seal, tamper and open cases passed; both profiles compiled
for arm64 iOS Simulator. No iOS execution or device result is claimed.
