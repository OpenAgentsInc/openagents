[mesh_e2e.ts](../../psionic/tests/mesh21/mesh_e2e.ts); its

The independent peer uses fresh test keys and independently verifies Coax's
AUTH and original event signatures. Authentic, newly signed wrong-context
fixtures separate binding failures from bad-signature refusal. Private
request/result digest checks use the exact decrypted envelopes, including
different whitespace, not a reserialized JSON body. Pass/fail label `x`
checks bind the exact replay envelope. Inconclusive observations use their
specified checker-owned report digest and never pretend to be model output.
All recorded phases reported no sanitizer errors or detected private-output
leaks. Later public-input tests additionally scan captured raw bytes for
opening-key material; earlier records retain their original string-based
checks rather than being relabeled as newer coverage.

## Boundaries

These are free accepted/jobs=1/null-payment claims under explicit buyer,
provider and checker policies, empty by default. A signed provider identity
is a declaration matched exactly, not remote model/hardware attestation.
The named toy CPU comparison context and operator-pinned tolerance are not
calibration evidence for arbitrary models or backends. Local fallback and
refused work produce no remote-job credit.

Witnesses and nonce-specific opening keys stay in memory and private
FIFO/AF_UNIX stdin; no signing or reusable conversation key is disclosed.
Only public receipts, verdicts, policies and input bundles are archived.
The generated public codec currently has a hard 1MiB ceiling despite the
schema/host's 2MiB ceiling; it refuses oversized data rather than truncating.
Category and raw-transport limits are finite; this does not promise
availability against unlimited relay noise.

Replacing/expired beacons can make historical online recomputation
incomplete. Preserve and serve the exact public bundle and explicit policy;
a bare digest is not enough to reconstruct vanished records. Readers must
refuse inconsistent/incomplete inputs rather than trust advertised totals.
This qualification is for native CLI flows, not a claim that Chapter21's
pool projection has been shipped into every web/mobile screen.

Linux GCC plain/sanitized public-bundle checks, the isolated v4 malformed
regression and the actual two-Pylon snapshot are recorded separately in
[Linux portability](2026-10-30-pool-linux-artifacts.md); those checks reused
frozen artifacts and did not repeat the Mac suite.
