# Public NIP guides and NIP-01 reconciliation — 2026-10-30

The `/nip` index and 22 `/nip/NN` pages cover the current shared-library
inventory plus the public production relay's NIP-11 declarations:
01, 09, 10, 11, 17, 19, 22, 29, 34, 40, 42, 44, 45, 49, 50, 59, 65,
67, 70, 77, 94 and 98. The catalog distinguishes Coax library, partial
support and production-relay declaration. It does not equate a declaration
with implementation conformance.

`apps/openagents-web/nip/catalog.json` is the reviewed inventory. The
generator `coax/web/nip-pages.py` writes the Coax arrays and public
HTML/Markdown twins; `--check` is part of the app build. Visible UI and
interaction stay in Coax/WebGPU. The C faces only bridge the Wasm ABI.

## What executes

The shared observer has 66 fixed public cases calling existing Coax modules:
event verification, standard tags, NIP-19 decoding, scoped comments, git
repository tags, expiration, NIP-42 templates, NIP-44 vector decryption,
scrypt buffer admission and supplied NIP-98 field checks. Other cases parse
the frozen production NIP-11 document or altered documents. Those examples
exercise metadata parsing, not deletion, messaging, groups, search,
negentropy or other advertised relay behavior.

NIP-49 demonstrates only existing scrypt buffer admission, and NIP-98 only
the supplied-field observer. Both are labelled partial. No example takes a
secret, signs with a real key, publishes an event or grants authority.

## NIP-01 reconciliation

The five-case REAL/ID/TEXT/SIG/KIND verifier remains intact. PARTS now
reflects code on main: signing, typed tags, metadata and shared message
codecs are implemented, giving 11 Coax components and the browser socket.
The tally describes component location, not complete protocol conformance.
The page and Markdown state that production keys still need the secret
audit and independent review, and live project consumers still need local
verification and shared-codec migration. The old claim that every project
event already used this verifier was removed. ALL NIPS and Escape open
the new index.

This changes documentation and observation UI, not the #4828 signer gate or
its audit owners' work.
