# Public pool bundle carriage

This slice wraps the generated `PublicPoolInputs` descriptor without adding
protobuf parsing, cryptography, signature admission, or private witness fields.
Returned policy/aggregate/event strings are untrusted views into the original
native input buffer. The independent reader must verify signed events and
recompute from locally admitted inputs before publishing or showing verification.

Authored pure policy: 6/6 source checks, 58/58 root-only mutants killed, zero
survivors and no equivalent waivers. The generated importer/runtime was not
changed or requalified. Runtime-only physical overlap observations and immutable
generated setters use a separate thin assembly bridge, following the existing
private witness encoder pattern. Its actual behavior is qualified natively.

The retained command is:

```sh
psionic/tests/mesh-pool-bundle-native.sh /tmp/oct30-pool-bundle-native
```

It compiles the actual Coax module to C, runs optimized and ASan/UBSan builds,
and uses independent `libprotoc 36.2` encoding/decoding. Both builds pass and
produce identical bytes. The harness checks:

- Native pointer ranges prove every returned string aliases original input.
- Original JSON whitespace and escapes survive byte-for-byte; the helper
  grants no JSON/signature authority to those opaque strings.
- Odd/even event counts, exact short buffer capacity, eight physical alias
  cases and undersized workspaces exercise actual generated setter/copy paths.
- Maximum 32,768-byte policy, 16,384-byte aggregate and 224-event cohort;
  each over-limit field/count refuses, and a short output-view list remains
  untouched on failed read.
- An exactly 1,048,576-byte bundle is accepted and independently decoded and
  re-encoded by protoc without a byte changing. One byte over refuses; a
  near-capacity message succeeds with exactly sized output/work buffers.
- A schema-valid independently protoc-encoded 1,147,208-byte message hard
  refuses with LIMIT, as do 2 MiB and larger inputs. Nothing is truncated.

The schema ceiling remains 2 MiB. The existing generated wire core has a
stricter 1 MiB effective limit, now explicit as `MBP_MAX`. No importer/runtime
change or hand-written wire workaround was made. Callers may provide 2 MiB
workspaces; the wrapper supplies only their usable prefixes to that core.
The CLI must report a hard snapshot failure above the implementation limit.

Small source fixtures are independently regenerated by protoc and compared
with their committed bytes before native execution. Source checks cover empty
and invalid UTF-8, private/unknown fields, wrong version, duplicate singulars,
nonminimal varints, descriptor limits, transactional failures, and every exact
authored shape boundary. Errors carry only codes and empty result fields.

The previously temporary pool-wire native consumer is also retained as
`psionic/tests/mesh-pool-wire-native.sh`. Its optimized/ASan outputs agree with
the independent JCS/SHA-256 oracle for every total, policy/tag commitments,
maximum role sets and empty counted-input hashes. The already-qualified
pool-wire implementation and imported gates remain unchanged.
