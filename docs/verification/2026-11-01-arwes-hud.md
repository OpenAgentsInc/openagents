# ARWES Coax HUD extension verification

Date: 2026-11-01. Base: `1e37eb87d0`. Upstream source:
`arwes/arwes@bdbaa0324900ee978d42036d1304a053c1fe54b5`.

The extension translates/adapts the relevant frame, motion, text,
background, effects, style, theme, timer and cue-state algorithms into Coax.
It adds 25 interactive specimens in a sixth HUD tab; the existing 18
specimens and four composed Grid scenes remain available. Framework-specific
ownership and DOM/CSS/SVG/Web Audio effects are classified in the
[source report](../verse/2026-11-01-arwes-coax.md), not claimed as a JavaScript
compatibility runtime. New application, shader and tooling logic is Coax.

The upstream revision was verified through the GitHub connector and compared
with an existing clean read-only source checkout. Its scripts, npm install,
builds and demos were not executed. The [source ledger](../../aethyr/ui/arwes/SOURCES.md)
inventories all 23 package indexes and all ten independent vanilla/core
families, classifying direct ports, typed adaptations and host-only code.
It records and verifies 98 exact file hashes: 72 core source files, 23
indexes, license, README and standalone metadata. Unchanged pins were not
rechecked after documentation edits.

The [MIT notice](../../aethyr/ui/arwes/LICENSE) is byte-identical to upstream.
The generated local app serves a copy at `/arwes-license.txt`; the actual
browser journey checks its copyright notice. Translated modules retain
source and license comments. No upstream TypeScript/React runtime or package
dependency is shipped.

## Explicit limits

Geometry uses `f32` screen points and 64-segment ellipses. Concave frame fills
use bounded even/odd scan conversion with at most 256 rows. The compatible
Coax shader adds modes 5 (radial), 6 (rectangle) and 7 (disc) to the existing
twelve-float stroke/atlas ABI. No full browser/SVG pixel-parity claim is made.
Family profiles sample complete source enter/exit tracks; per-element
interruption inheritance is separate from `ArMotion`'s continuous value API.

Typed colors omit arbitrary CSS/LCH parsing; text is bounded to 256 Unicode
scalars/1,024 UTF-8 bytes and does not perform grapheme shaping. Seeded
randomness replaces global random calls. Timers use caller-owned finite
time and FIFO equal-deadline order. Cues use 16 caller bits, explicit override
flags, a current pending request and load tickets; their documented
aggregation/cancellation behavior is not upstream's callback queue.
