## Measured boundaries

Optional `roomtrace=1` creates a separate Coax observer for each concrete
browser WebSocket. It never waits before gameplay sends or rendering. The
native SDK supplies timestamps to the Coax kernel only after an actual new
input is accepted, that exact sequence successfully steps, and the complete
D enters the addressed socket queue. The client records the raw WebSocket
callback before its host event queue. Application requires both a covering ACK
and a complete state tick. The first subsequent render submission and its GPU
completion belong to the same engine, socket and device. Retirement and the
two-second deadline invalidate outstanding observations.

This is an ACK/state-consuming frame boundary. It does not assert physical
scanout or prove a particular pixel changed. Interpolation delay is separate.
The four-timestamp model retains signed offset/uplink/downlink intervals, with
declared 100us quantization, 100ppm drift and five-second freshness assumptions.
These are not measurements of arbitrary remote clock stability. No absent,
expired or inconsistent interval becomes zero.

History has 64 entries. `coaxial.roomTrace()` returns completed raw observations
and expired/refused/missing counts. Up to four retired observers remain
inspectable. Native report encoding is distinct from actual queue admission;
the existing complete-byte observer includes these optional frames in its `?`
message class. Ordinary sessions allocate no browser observer. Native ordinary
inputs use the inactive fast path before any seat-state copy or D parsing.
