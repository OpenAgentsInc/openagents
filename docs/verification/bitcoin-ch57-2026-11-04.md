# Bitcoin chapter 57 qualification, 2026-11-04

The implementation is `coax/lib/bitcoin/validation.coax`. All block and
coin decisions execute in Coax. Its private workspace must be discarded on
any refusal; the function publishes no tip or block-index validity level.
The light explorer and its proof-of-work-only profile are unchanged.

Compiler: coax0 0.48.0, SHA256
`cdaceb89e69c8d523e41242a940af34774e8b6b4f945998c2d3bf38486c357fb`,
installed by `coax/build.sh` from the verified release cache. Native C uses
Apple clang on arm64 Darwin. No Wasm qualification is claimed.

The independent reference is the official Bitcoin Core 32.1.0 arm64 Darwin
binary, checked against the archive SHA256 recorded in
`bitcoin/fixtures/validation/SOURCES.md`. Every reference node has an
explicit private temporary data directory, no wallet and no peers. Cookies
stay private and are never retained in artifacts.

The full Coax import closure has 624 checks; 24 check the new block pipeline.
The native oracle agrees with 35 actual Core regtest verdicts, including
parent/child spending, duplicate inputs and double spends, money bounds,
coinbase placement/height/value/length, absolute and relative locks, false
scripts, Merkle failures, witness commitments and weight, sigop limits,
and header proof of work/difficulty/time/version. Accepted cases have exact
independent post-block coin comparisons.

Four additional actual Core cases cover testnet4 and signet block 1: each
rejects a changed body, then accepts the valid body for that same header.
The signet case caught and fixed the challenge/Merkle rejection order.
Coax now checks signet's challenge before the Merkle root, after decoding.

Thirteen historical fixtures cover 9,496 transactions and 24,228 supplied
predecessor coin records. All pass full script checking, match the recorded
fees, and match Python's independent exact post-block coins. They include
mainnet soft-fork activations, the two BIP-30 repeats (with the original
unspent coin included), both script-flag hash exceptions, and testnet4 and
signet block 1. Mainnet's admitted parent context is supplied by the
independent archival reference; this is not an own-node sync from genesis.

Both packed and indexed coin workspaces are checked. ASan/UBSan checks
cover the real historical blocks and the live Core regtest corpus. The
packed sanitizer checks were split by block after the original 120-second
per-case limit proved too short; each later invocation stayed bounded.
The indexed arena removes the packed table's repeated whole-tail moves.
On the recorded Mac run, native historical time fell from 154.650 seconds
for the packed table to 26.433 seconds for the indexed arena. The indexed
ASan/UBSan historical run took 160.839 seconds across all 13 blocks.

Mutation uses the idle `coderos-4080` worker (28 cores) as well as the Mac.
Its Coax 0.48.0 compiler's provenance is verified against the same checkout;
Linux binary SHA256 is
`54308753598854075405f995a04eb94f64eeb85f231ee6840a42e77afe6d2e80`.
Each worker command has an automatic 840-second cutoff.

Mutation scope: the new physical source unit, `--root-only`; all imported
baseline checks remain mandatory. No new equivalent-mutant annotations are
used. The complete 1/1 receipt contains 425 mutants: 425 killed, zero
survivors. The Mac compiler successfully merged the worker receipt against
the exact local source, verifying its source/profile binding. Earlier
diagnostic runs found missing model cases and redundant operations; those
were corrected rather than exempted. One local diagnostic shard exceeded
the 15-minute limit and was stopped; the final worker run finished within
its automatic cutoff.

The worked example has exact debug and release transcripts in
`bitcoin/fixtures/validate-block.out`. It computes two fees of one satoshi
and the 5,000,000,002-satoshi reward ceiling, then shows distinct refusals,
a real ECDSA spend and a two-input Taproot spend.

Repository tools-check reports the same 15 unrelated files without a Firm
reason header as the previous explorer qualification; the new independent
oracles carry reason 2 headers. The full book gate has a separately recorded
pre-existing capability-claim mismatch for `verse/everglade/gpu.bindings`.
Targeted chapter registry, contents, source-listing, local-link,
example-inventory and count checks pass after promotion.

Full-node money admission still waits for chapters 80, 93 and 118. Undo,
validated chainstate publication and reorganization remain the next work.
