## Scope

Storage admits framing and checks undo's previous-hash-bound checksum on a
read. It does not validate blocks or apply undo, and cannot detect block body
corruption from framing alone. Undo construction, reorgs, file rollover,
chainstate commit ordering and the index-to-file durability relationship
remain later node work. The file adapter requires exclusive ownership;
snapshot size/mtime checks do not establish a general filesystem lock.
GitBook publication is separate from this source change.
