Behavior:
The whole-program authority cache stores frozen capacity facts in its v2
private record. Cold and warm C and diagnostics match byte for byte.
Formatting is applied after reuse, so text, one-line JSON and rich JSON
share the same facts. The near-limit threshold participates in identity.
A truncated/invalid record is a miss and publishes no partial facts.
Per-check reuse keeps quiet passing checks. Diagnostic-bearing checks
rerun in the parent, with current source locations and detailed consumers.
Parallel diagnostics match a one-job run. Checks that retain storage keep
the existing sequential fallback. An earlier quiet pass survives a later
failed or diagnostic check and can be reused when that source is restored.
No diagnostics are suppressed and no budget is raised.
