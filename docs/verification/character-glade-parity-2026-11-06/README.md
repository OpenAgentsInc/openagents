# Reference comparison pass

Eight visual iteration captures were compared with the supplied Preview_1.jpg.
The retained captures show the final desktop, phone and unobstructed scene.

The pass lowers the horizon, rebuilds the cliff and winding path composition,
colors the rear ridge gold, adds loose stones/foreground plants, brightens
foliage interiors, adapts restrained source tree-card expansion, and stores
26,911 procedural curved tufts within 32 MiB. Smaller cloud banks and thin
cirrus replace the large blurred clouds. Coverage fades grass edges toward
the meadow; dirt has subtle irregular seams.

This remains an approximation. Exact source scene placement was not recovered.
The cliff/plant distribution, analytic shadows and procedural atmosphere still
differ visibly from the original. These captures do not certify image parity.

The receipt records focused tests, native hardware WebGPU compilation, actual
character interactions/save/zoom/pan, binary geometry bounds, and byte-identical
wardrobe payloads. The scene JSON pins source assets and generated artifacts.
