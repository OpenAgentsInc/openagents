# Coax bounded integer-only canonical JSON

Task `nostr-jcs`, worker `codex-nostr-codecs`, 2026-10-28.

## Supported profile

`coax/lib/nostr/jcs.coax` implements the selected safe-integer envelope profile.
`jcs-memory.coax` supplies `jcs_canonicalize(text, out)`, observing physical
overlap while the checked core owns admission, ordering, limits and output.
The result is `JcsResult { written, error }`.

Numbers must be plain JSON integer tokens in ±9,007,199,254,740,991. Negative
zero emits `0`. Fractions, exponent notation and unsafe integers refuse, even
in unknown fields. This is explicitly **not general RFC 8785 floating-point
number serialization**. Arbitrary member names remain data: a string-valued
member named `kind` is accepted; event-specific field typing is separate.

Decoded property names sort by unsigned UTF-16 code units, including surrogate
pairs for astral scalars. Arrays retain order, and object sorting applies at
every level. Escaped-equivalent duplicate names refuse within their own object;
names in different objects remain independent. Unicode text is preserved
without normalization. Mandatory escapes use the canonical lowercase/short
forms. Lone surrogates, malformed UTF-8 and I-JSON noncharacters refuse, whether
raw or escaped. The latter includes U+FDD0–FDEF and each plane's FFFE/FFFF.
These rules follow [RFC 8785](https://www.rfc-editor.org/rfc/rfc8785.html)
and [I-JSON §2.1](https://www.rfc-editor.org/rfc/rfc7493.html#section-2.1).

| Resource | Limit |
| --- | ---: |
| Original input and supplied output capacity | 524,288 bytes each |
| Container depth, from the hardened JSON parser | 16 |
| Raw and decoded individual string | 65,536 bytes |
| Value/container nodes, excluding member-name tokens | 2,048 |
| Object members across all objects | 1,024 |
| Decoded member-name storage across all objects | 65,536 bytes |
| UTF-16 comparison iterations, including end comparisons | 1,048,576 |

The core uses bounded local arrays and retains input ranges rather than copying
entire values. It parses and validates the complete input, sorts member links,
then measures canonical output before writing. Capacity, format, Unicode,
duplicate and work/size refusals report zero written and preserve the entire
output. Success preserves output tails. Input/output overlap refuses, and the
source bytes remain unchanged. Native callers own valid, stable allocated spans;
count/overlap checks are not a proof of pointer ownership.

Error values are `JCS_LIMIT` (1), `JCS_JSON` (2), `JCS_STRING` (3),
`JCS_DUPLICATE` (4), `JCS_OUTPUT` (5), `JCS_ALIAS` (6), `JCS_WORK` (7) and
`JCS_NUMBER` (8). Zero is success. Parser refusal includes its grammar, raw
UTF-8, depth and raw-string bounds; decoded scalar/noncharacter failure is
`JCS_STRING`.

JCS creates a separate canonical buffer for contract/artifact digests. Original
signed Nostr bytes stay caller-owned; NIP-01 event-ID serialization is a
separate operation. This primitive does not admit a schema, verify a signature,
authorize an operation, manage keys or promise secure erasure of its temporary
decoded strings.

## Verification

```sh
coax/bin/coax test coax/lib/nostr/jcs.coax
coax/bin/coax mutate coax/lib/nostr/jcs.coax
python3 coax/tests/nostr/jcs.py --evidence /tmp/jcs.json
```

Checks initially failed before the canonicalizer existed. Exact-capacity,
measurement, UTF-16 unit, decoded duplicate and resource-endpoint checks were
expanded from mutation findings. Redundant branches and unused initialization
were removed rather than exempted. Final scope: **43 check groups pass and
1,688/1,688 mutants are killed**, with no exemptions. This includes the loaded
JSON/parser-policy closure; totals are not disjoint from those modules.

The independent Python oracle sorts keys using big-endian UTF-16 bytes; a
separate Node oracle uses ECMAScript string ordering and canonical primitive
serialization. The two agree before comparing the Coax candidate. Cases cover
astral/BMP order differences, control/empty keys, Unicode normalization
distinctions, negative zero and safe-integer edges, nested values, invalid or
escaped duplicates, malformed UTF-8, surrogates/noncharacters, exact/oversized
limits and comparison-work exhaustion. Seed 8785 generates additional nested
values; floating/exponent refusals are checked explicitly under this profile.

**388 records** pass checked and release native C under ASan/UBSan, and the
same records execute in actual Wasm under Node/V8. The independent oracles
agree on 326 supported records; 62 records assert explicit refusal. Every
valid record also checks exact and one-short
capacity, zero written on refusal, no partial output and unchanged originals.
Native/Wasm boundary cases separately exercise overlapping and invalid metadata
spans. Unsupported macOS leak detection is disabled; no leak-check claim is
made. C test faces only carry scalar calls and observations.

unit test's Hello/Sub/Second deck through `coax/web/unlock/lib.ts`'s actual
`parseDeck` and `jcs` functions. No keys, encryption or publication were used.

digest and a corresponding deterministic envelope. Both independent oracles and

reserialized signed event or an encrypted Nostr wrapper.

mid-run. No compiler bootstrap, full app suite or TestFlight build was repeated.
