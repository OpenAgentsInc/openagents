# Coax 0.13.0: R0 engine evidence and source debugging

## Result and scope

The first R0 slice ships real cast/robot/collision benchmarks, a Debug-only
capture through the actual iOS Grid/Metal frame path, compiler phase/size
reports and original Coax source debugging. R0's adoption gate is **open**:
the proposed 5% median performance budget is missed. This is not a full
engine-parity result, physical-phone benchmark or independently approved gate.

Implementation began in a fresh detached worktree from remote main
`04917871cb`. The final integration also retains the subsequent main changes,
including iOS build 1055's audio fixes and Coaxial's Wasm/WebGPU splash.
The splash also compiles successfully with 0.13.0; that smoke is a Wasm
build check, not a new browser runtime claim. Measurements identify their actual
source revision, dirty state, input hashes and compiler binary hash; they do
not pretend the final report-writing commit existed before measurement.

See [methodology and runnable commands](../../metareal/benchmarks/README.md),
[native debugging](../../coax/DEBUGGING.md), and
[remaining R0 gates](../../coax/ROADMAP.md#3-r0--establish-the-adoption-gate-now).

## Real kernel comparison

Hardware: Apple M5 Max, macOS 26.4 arm64. Toolchain: Apple clang 21.0.0
(`clang-2100.1.1.101`). Native/reference flags match within each profile:
`-O0` or `-O2`, `-g`, `-ffp-contract=off`, no LTO. The app-style profile keeps
checked Coax runtime arithmetic with external `-O2`; `--release` additionally
selects wrapping runtime integers.

The real bundled MRC1 cast has 65 player joints and 402 robot joints. There
are 180 warm-up frames followed by nine repeats of 540 measured frames,
alternating native/Coax call order. Every player palette element agrees
within `8.7618828e-6`, below the frozen `0.0002` absolute tolerance. The
reference's animation-state inputs are shared with Coax; independent parity
is for pose evaluation, not the entire animation controller.

| Profile | Coax pose median / p95 (µs) | Native median / p95 (µs) | Median ratio |
| --- | --- | --- | --- |
| Checked `-O0` | 107.875 / 195.625 | 37.125 / 54.292 | 2.906× |
| App-style checked `-O2` | 5.542 / 10.875 | 2.709 / 4.500 | 2.046× |
| Wrapping release `-O2` | 4.666 / 8.916 | 2.708 / 4.250 | 1.723× |

App-style robot pose/body construction median: 8.583 µs; player collision
against those capsules: 2.292 µs. Their full distributions are retained too.
The pose coefficient of variation is 0.347 for Coax and 0.318 for native in
that profile. These microsecond measurements have visible noise and are a
baseline for profiling, not an SLA. The native reference's temporary vector
allocates once per frame at `-O0`; clang eliminates it at `-O2`. It was not
edited out. Coax pose, robots/bodies and player collision each observe zero
heap allocation calls inside the timed kernels in every profile.

The pinned original source, explicit f32-reader adaptation and corpus hashes
are in `metareal/benchmarks/contract.json`. The original evaluator/blending
code stays byte-exact. The adaptation/full-body mask/tolerance still need
independent review. Allocation hooks cover only the documented thread and
ordinary allocation entry points; they do not establish zero Swift/Metal,
system, aligned or other-thread allocations.

### Compiler and iteration observations

The same run retains first and repeated codegen phases, external wall time,
peak child RSS, generated bytes, first/repeated C compile and separate link.
For app-style Cast: generation wall time about 17 ms, peak RSS 33.9 MiB,
168,604 generated C bytes, native C compilation about 231 ms. Link of the
three libraries, native reference and harness takes about 31 ms. These
numbers include debug mapping; they are workload-specific single-shot
invocations with uncontrolled OS caches. They do not measure incremental
compilation or a cold machine.

`load` includes source discovery's physical-unit syntax validation. Later
lex/parse buckets describe the combined program. The driver is a native host
observer; clocks are not available in `#run`. Full asset/install/launch and
GPU-preparation attribution, stable device tails and repeated complete app
iteration remain unfinished R0 evidence.

## Source debugging

`--debug-info` maps authored statements through C `#line`. Schema-1
`--source-map` adds source SHA-256, physical ownership, procedure names and
parameter/local/loop-variable names and Coax type labels. Plain C generation
stays unchanged without the option, so seed reproduction remains exact.
Default debug native builds enable line mapping and retain the debug object
required by Darwin's linker map. Release mapping is explicit.

Nine actual regression cases pass: original loaded-file breakpoints,
step-over and values 20/40/42, multi-C-statement lowering, Coax call stacks,
native compiler diagnostics, sanitizer abort traces, escaped paths, stale
source rejection, separate-library private names, and failed report output.
Some cases exercise more than one behavior. The live Simulator app was also
attached to LLDB: `metareal_cast_pose` stopped at `cast.coax:425`, the map
presented `Cast`/`Anim` values and the stack reached the Swift frame renderer.
The optimized app warns that some variables/steps may be unavailable.

This is line/name integration, not a Coax expression evaluator, complete
native type visualizer, Metal mapping or physical-device crash-symbolication
proof. Generated protobuf functions collapse to the import directive; hashes
cover physical Coax files rather than all descriptor/build inputs. The
emitter, native debugger/toolchain and driver remain trusted. Map
hashes reuse checked Coax SHA-256; the optional debugger Python script is
presentation tooling, never a compiler/app build dependency.

## Checks run

- Python-free `coax/build.sh`: exact frontend seeds, authority and mutation
  gates and complete compiler-module fixed point passed.
- `coax/tests/run.sh`: 82 native fixtures and all compiler/kernel suites
  passed, including nine debugger cases.
- `coax test metareal/benchmarks.coax`: eight checks pass;
  `coax mutate`: 104 mutants, 104 killed, zero survivors. No exemption added.
  The tied-sample check enforces linear insertion work within its evaluator
  budget; it kills a comparison mutation that would do quadratic equal work.
- Cast/player Coax checks pass; `metareal/test_cast.sh` passes ASan/UBSan,
  3,600 real-asset frames, corruption refusal and Foreman-leg collision.
- The real benchmark passes all three profiles under ASan/UBSan, including
  native NaN/Inf/capacity rejection by the Coax statistics routine. Those
  timings are sanitizer evidence, not comparable performance baselines.
  An explicit `--enforce-budget` run returns exit 1 for the proposed timing
  miss after passing output/allocation checks; the default correctness run
  succeeds while reporting that same separate performance status.
- Book debug/release examples, native sanitizer hosts and linked excerpts
  pass. All 21 official protoc interoperability cases pass. The book's exact
  two-file LLDB walkthrough independently shows 40 before step-over and 42
  afterward. The nine debugger cases also pass with an ASan/UBSan-instrumented
  compiler (process-lifetime arena leak detection disabled).
- The dedicated iOS 26.5 Simulator passes Home, Haunted House and R0 frame
  UI tests. It is a task-owned device, separate from other working simulators.

## What closes the rest of R0

Profile and reduce the pose cost without weakening checks, changing the
reference or silently changing arithmetic. Re-run the frozen comparison and
agree a real device/frame-tail budget. Complete asset/install/launch/GPU
preparation accounting and physical-phone runs. Add the single release/status
source and publication drift gate. Obtain independent reference/invariant
review and enforce that review outside an author's editable compiler/checks
on owned infrastructure. No GitHub-hosted CI is introduced by this slice.
