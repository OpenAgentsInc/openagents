# R0 pose optimization: the frozen median gate passes

## Result

The existing nine-repeat `--enforce-budget` run passes all three profiles on
Apple M5 Max, macOS 26.4 arm64, Apple clang 21.0.0. This closes the previously
measured pose median gap. R0's device, tail, full-loop, status-generation and
independent-review requirements remain open.

| Profile | Before Coax/native medians (µs) | After Coax/native medians (µs) | Before ratio | After ratio |
| --- | --- | --- | --- | --- |
| Checked `-O0` | 106.750 / 36.875 | 35.958 / 34.791 | 2.895× | 1.034× |
| App-style checked `-O2` | 5.625 / 2.833 | 2.084 / 2.583 | 1.986× | 0.807× |
| Wrapping release `-O2` | 4.625 / 2.708 | 2.375 / 3.208 | 1.708× | 0.740× |

Every player palette element still agrees within `8.7618828e-6`, below the
existing `0.0002` absolute tolerance. Observed Coax pose, robot/body and player
kernel heap allocations remain zero. Each profile retains 4,860 measured
frames after the existing 180-frame warm-up, with paired alternating call
order. No samples are discarded.

The reference files, reader adaptation, corpus, contract, benchmark driver,
native harness, workload and flags are unchanged. The baseline is from a fresh
worktree at remote-main `1ed5d2d042`; the measured change is in
`verse/cast.coax`. The raw reports bind their actual compiler/source hashes
and dirty state, not a future report-writing commit.

## What changed

A sampled walking-pose loop showed frequent byte-decoder calls and `memmove`;
the emitted C passed the 488-byte `Cast` value through out-of-line per-joint
helpers. Clip selection, skeleton reads and yaw setup were repeated too.

The Coax rewrite:

- Prepares clip frame offsets, skeleton parents/bind positions and yaw once
  per pose; the full cast descriptor stays outside the joint helpers.
- Decodes each needed skin row once into bounded stack caches. Parent-before-
  child admission ensures cached parents are already written. Every byte,
  view and cache access retains its checked semantics.
- Uses zero-default internal rows for overwritten scratch data, avoiding
  construction of 130 identity quaternions per sample in unoptimized code.
  Public quaternion defaults are unchanged.
- Writes the twelve matrix fields directly and scalarizes vector rotation,
  preserving the original arithmetic grouping while removing temporary arrays
  and small helper-call chains.
- Avoids unused second-frame decoding at zero interpolation, while still
  normalizing the first relative rotation. Held final frames retain their
  original non-interpolating path. A nonunit input regression pins this.

This preserves the existing numerical contract, not a general signed-zero bit
identity guarantee. No unsafe load, compiler optimization-flag change, heap
cache, new wire format or asset conversion is introduced.

### Explicit memory and tail costs

The caches trade bounded stack storage for repeated decoding/copies. Clang's
`-fstack-usage` observation at app-style `-O2` reports 5,488 bytes for
`verse_cast_pose` and 4,048 for its nested `pose_samples`, plus lower helper
and caller frames. These per-function observations are not a whole-thread or
sanitized-build stack bound.

| Profile | After Coax p95 (µs) | After native p95 (µs) | Coax/native coefficient of variation |
| --- | --- | --- | --- |
| Checked `-O0` | 55.708 | 49.750 | 2.630 / 0.212 |
| App-style checked `-O2` | 3.166 | 3.917 | 0.251 / 0.209 |
| Wrapping release `-O2` | 3.917 | 5.333 | 0.385 / 0.353 |

The debug run includes a retained 6.713 ms outlier. Its median passes the
proposed gate, but its variance/tail is not a device-frame guarantee. Native
frequency/system load also varies across profiles and runs; compare paired
ratios and raw distributions rather than assuming all absolute times share a
fixed clock. The proposed threshold remains 1.05 and is not an independently
approved adoption or frame-tail budget.

## Affected validation

- Check-first clip-plan, analytic sampled-motion, normalization, skeleton,
  last-word and cache-row regressions: 32 Cast checks pass. Existing matrix,
  quaternion, cross-fade, held-frame and patrol checks still execute.
- `verse/test_cast.sh`: ASan/UBSan, 3,600 motion frames plus dance, damaged
  and non-finite asset refusal, robot capsules and Foreman collision pass.
- The unchanged reference harness passes all profiles under ASan/UBSan.
  Instrumented timings are correctness evidence, not a performance baseline.
- The final nine-repeat normal run with `--enforce-budget` exits zero, checking
  palette values, allocations, independent rank/median recomputation and pins.
- Only the affected `R0UITests` app test runs on the task-owned iPhone 17 Pro
  Max Simulator, iOS 26.5, build 1056. It passes through the normal Grid/Metal
  path. All seven metrics have 540 samples; all 540 command buffers complete,
  GPU errors are zero and GPU clocks are available.

The separate R3a checker slice is integrated from its own fresh worktree.
Its [evidence](../../coax/verification-local-borrows.md) records 553 checks,
3,762 killed mutants with zero survivors, seed/bootstrap fixed points and
focused native/sanitizer/diagnostic cases. On this exact optimized Cast source
(`e9085955d0112eba46465316f4074b02048060dca76003ec30de869ab1a7eb04`),
trusted and final compilers emit byte-identical checked/release C, headers and
source maps. Checked C is 186,443 bytes; release C is 185,583. That identity
allows the existing kernel performance validation to be retained rather than
rerun for an unrelated checker diagnostic. The final app/sanitizer integration
uses the updated compiler.
