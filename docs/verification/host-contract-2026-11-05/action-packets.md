# Measured action outboxes

The v1 ordinary browser now measures the selected action outbox before
forming a byte view, decoding it or executing any effect. Everglade's
additive `coaxial_outbox_capacity(state)` reports the actual array selected
by the existing bar/place/city outbox route, using `sizeof`, including the
place helper's own storage. It changes no action bytes or gameplay. The
recording face reports its actual 64-byte output allocation.

The common `action-packet.coax` allows an empty action without storage.
A nonempty action requires the capacity export and the existing checked
`htb_copy_span` for the whole allocation/payload/address limit. Missing,
short, null and wrapping/out-of-memory spans refuse before a view. A
refused action has no platform effect, receives exactly one acknowledgment,
then gets message604 outside the acknowledged producer call. Admitted bytes
are copied before acknowledgment. Pre-v1 readers retain their existing path.

The actual ordinary `host.js` runs ten recording-face cases. All **110
observed fields** must match, including pointer/capacity/length read counts,
no thrown view/decode, one action acknowledgment, the actual action code,
604 count/order, the real hash effect and a later producer frame. The cases
are a valid output, length beyond capacity, null pointer, address near the
physical memory end, zero/short capacity, capacity extending past memory,
two empty packets with unused null/end pointers, and a separately linked
Wasm with the capacity export physically absent. Refusals leave the hash
unchanged. Both empty actions still execute; their pointer/capacity getters
are never called. Required failures publish no successful prefix.

The first [physical observation](action-packets/first-product.json) retained
correct action fields but observed no later frame through headless RAF alone.
It is not a pass. The corrected driver explicitly offers a later ordinary
host frame; it does not change a product limit or bypass the frame producer.
The initial artifact-list writer also emitted malformed JSON; its
[raw output](action-packets/first-receipt-malformed.txt) is retained. The
writer now parses and writes that array through the checked JSON writer;
no product predicate or expected observation changed. The final [source-fenced observation](action-packets/final-product.json)
includes actual browser-fetched artifact hashes. All ten cases pass.
This is action transport/effect admission, not a new GPU parity, ordinary
realm performance or complete native-window result.
