# Native physical action packets

Linux now calls the same `hap_span` authority as the
[browser](action-packets.md) before viewing a nonempty outbox. Empty actions
read neither pointer nor capacity. It copies admitted bytes before the one
acknowledgement, then executes the platform effect. Missing/invalid storage
is acknowledged once and produces604 on a later poll, outside producer
dispatch. A synchronous clipboard callback can explicitly refuse; unavailable
clipboard also queues604. Hash replacement owns its bytes until replacement
or engine close.

The real dispatcher passes every one of the common110 observations normally
and under ASan/UBSan/LSan. Two physically distinct recording faces exercise
the actual missing-export path. Native mode7 refuses a declared complete
allocation extending one byte beyond `UINTPTR_MAX`, while keeping its16-byte
logical payload addressable. No native policy sentinel replaces that fact.
Valid/empty hash effects execute; all seven malformed/missing cases execute
none. All cases acknowledge once, preserve acknowledgement-before604 and
continue actual producer frames.
