## Native ABI and actual producer execution

All six exact C units compile sequentially with native clang at O2,
`-ffp-contract=off -fno-fast-math`. The matching current face compiles with
`COAXIAL_NATIVE_ADDRESS` and links into its own dynamic image, preserving the
native-only v1 opt-in and web's existing version. Shared-carrier reuse is
explicitly qualified through this native consumer; a matching basename alone
is insufficient. No generated C or header is edited or relabelled as the
producer-only wrapper's missing cache entry.

The actual native image constructs and advances 16 CPU frames through the
normal SDK. Its bank metadata, byte spans, command draining and default asset
demand pass. All six producer units, the native face and the SDK also pass this
workload instrumented with AddressSanitizer. `metal-build producer --sanitize`
now applies instrumentation to the face and dynamic-library link too. macOS
leak detection is explicitly disabled; no UBSan/whole-platform claim is made.
