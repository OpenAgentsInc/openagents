# Chapter 3: a tensor is a view of memory — 2026-10-29

This chapter adds a separate bounded borrowed CPU f32 view layer. Chapter 2's
contiguous, nonempty admission and every existing model engine are unchanged.

Product logic is `psionic/lib/tensor-view.coax`: rank 0–4 shapes, signed strides,
absolute offsets, scalar/zero-element semantics, bounded slicing, transposes,
read-only broadcasting, conservative alias queries, gathered materialization,
staged writes and authoritative storage versions. Native code observes address
ranges, including owner metadata; it implements no indexing or admission policy.

The caller owns one authoritative record and allocation. Retirement invalidates
all views; allocation reuse needs a fresh identity/epoch. Successful nonempty
writes increment its version once; failed/empty writes do not. Saved tokens
report modified or stale state. This is the storage mechanism for later backward
integration, not a claim that chapter 106's general autograd engine exists.

## Focused checks

- Authored Coax checks cover scalar/empty/contiguous shapes, products and caps,
  signed/gapped layouts, reversal, transposition, canonical singleton strides,
  slice endpoints, broadcast rejection, stale/foreign records, integer extremes,
  finite representations, refusal publication and storage-version overflow.
- An independent native oracle explicitly enumerates addresses and uniqueness
  for **28,350** two-dimensional layouts, using extents 0–4, strides -4–4 and
  every origin 0–13. It checks admitted offsets and prevents false writable
  injectivity proofs, without constructing expected answers with Coax helpers.
- Native tests cover rank 0–4 transposition round trips, a reversed/gapped
  materialization and write, signed zero, all nonfinite encoding classes,
  actual address aliases (including owner metadata), short spans, saved-value
  invalidation, retirement/reuse and version saturation.
- Zero-element null spans succeed without reading memory. A 1,048,576-element
  transpose compares every output to its independently indexed source.
- The book example has a frozen hand-written transcript and linked source
  listings. The chapter uses `jai` fences; command blocks use `shell`.

## Limits

Strides are measured in f32 elements and bounded in absolute value. Writable
injectivity is a sufficient sorted-stride span proof, not an exact alias solver.
Read-only overlapping views are allowed. Interval alias queries can report a
possible overlap for disjoint interleaved cells. Every broadcast is read-only.

The profile copies finite f32 representations without numerical arithmetic;
it introduces no dtype/device dispatch or gradients. Existing contiguous
operators are not silently widened to accept these layouts. The native caller
must preserve truthful pointers/extents, lifetime, alignment, one authoritative
record per allocation, fresh identities/epochs, mutation through this boundary
and exclusive access. Forged records and writes through external pointers are
outside the contract. Automatic allocation/refcounts, concurrent transactions,
device placement and general saved-tensor integration remain later chapters.
