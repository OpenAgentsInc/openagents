## Native-only defect controls

The evaluator refuses constructing actual non-finite floats at compile time.
Coax checks therefore test their raw bit encodings; native tests supply the
actual float values. Two manual controls additionally challenged that boundary
using temporary copies of our own tensor source:

- Replace the finite-value iteration with an indexed loop starting at one,
  so only the first source value escapes validation.
- Replace it with an indexed loop ending at `source.count - 1`, so only the
  last source value escapes validation.

Each variant compiled successfully and then failed the native harness's
expected-status assertion (exit signal 6). The variants were not installed or
committed. The unmodified implementation passes. These controls supplement
the 68 source-level mutants; they do not extend that mutation count or imply
that generated loops or arbitrary native defects are exhaustively mutated.

## Supported scope

Contiguous binary32 shapes, rank 0–4, canonical inactive dimensions, scalar
count one and a 1,048,576-element teaching-profile limit. Layout admission
checks products before multiplication. Index results revalidate the shape;
a failed metadata result has zero payload and its status must be inspected.
Copy requires exact logical source length, adequate disjoint destination and
scratch capacities, and finite source data. It stages before publication;
all refusals leave every caller span unchanged and report zero written values.

Native callers still supply truthful aligned float allocations, valid extents,
lifetimes and exclusive access. The shared observer measures declared address
ranges, including unused writable capacity; it cannot prove ownership of an
arbitrary pointer. The pure checked entry point assumes a truthful overlap
observation. The ordinary native wrapper supplies that observation.

No dense arithmetic, strided/broadcast/empty tensors, additional dtypes,
autodiff, imported model, device/backend, serving, physical-phone performance
or general memory-safety proof is established here. M1 remains partial until
the chapter 3 dense-operation work is implemented. No owner action was needed.
