## Numerical differences

The normal half-probability fixtures, all finite packed conversions and seeded
uniform bytes are exact on all three backends. The general dropout reference
uses `abs(actual-reference)/max(1,abs(reference))` and a keep threshold of 21845:

| Output dtype | Frozen bound | Maximum observed, CPU/CUDA/Metal |
| --- | --- | --- |
| f32 | 0.000002 | 3.38773756e-08 |
| f16 | 0.001953125 | 9.59016115e-05 |
| bf16 | 0.015625 | 0.00145610409 |

These are rounding differences from a double mathematical reference, not
measured CPU/GPU disagreements on these normal fixtures. The reported maxima
are the same across the tested modes/backends.

The subnormal fixture adds each of f32 bit patterns `00000001`, `00010000`,
`007fffff`, `00800000` to itself in evaluation mode. CPU and CUDA preserve all
four expected results. Metal flushes the first three inputs to zero, including
the case whose exact sum would be normal; the fourth normal input is preserved.
Every cast still preserves all finite bits. General Metal arithmetic therefore
has an explicit flush-to-zero input profile; universal arithmetic bit equality
is not promised. The diagnostic permits this behavior only for subnormal
inputs, never for the normal control value.

## Environment failures and limits

An initial Metal pipeline compilation lost its XPC compiler connection after
retries. The isolated native rerun passed all four configurations without a
source change. We retained passing CPU/Coax results rather than rerun them.

CUDA's first host-ASan run failed during `cuInit` with an allocation error.
Allowing the CUDA driver's virtual-address mappings through ASan's shadow gap
(`protect_shadow_gap=0`) advanced to NVRTC, whose builtins then required the
correct `LD_LIBRARY_PATH=$HOME/cuda-13.2/lib`. With both set, debug and release
host-ASan/UBSan runs passed. The focused CUDA runner sets the shadow-gap option;
the user supplies their installed NVRTC dependency path. Instrumented host
accesses still receive ASan checks; NVIDIA device accesses are not covered by
host sanitizers. No compute-sanitizer result is claimed.

Driver poisoning is checked as Coax state transitions; a real GPU driver fault
was not injected. Exhaustive rounding over all f32 values, all GPU hardware,
thread-safe host use, physical GPU ordinal selection, statistical training-quality RNG qualification,
preemptive cancellation, automatic placement, in-place updates, autograd and
throughput qualification are outside this chapter.

Full mutation runs were omitted under the owner's explicit focused-check
instruction. There is no zero-survivor mutation claim for this new profile.
Earlier passing 2a/3a gates were not repeated on unchanged files. No owner action
is required.

The final rebase retained both sides of the example-manifest append conflict,
