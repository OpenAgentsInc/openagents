## Scope and remaining work

The runtime accepts trusted typed caller pins and borrowed immutable original
bytes. It does not parse an untrusted manifest and promote it to authority.
Matching hashes bind bytes, not their supplier's identity, license, model
semantics or authenticity. Origin/revision strings are labels; a real model
qualification still needs pinned upstream provenance and reference tensors.
Config and tokenizer are identity-bound opaque sidecars in this chapter.

The profile supports rank 0–4, positive dimensions/scalars, BF16/F32 and bounded
printable unescaped ASCII identifiers. Empty tensors, other dtypes, compressed
weights, arbitrary metadata/index extensions and escaped/non-ASCII identifiers
are refused explicitly. Artifact file/inventory budgets differ from CPU
execution budgets. Whole-file immutable views can be mapped by a host, but
streaming filesystem I/O and a full-model residency planner are not implemented.

Public file/bundle inventories change only on success. Metadata drafts may be
dirty on refusal; decode reparses the original file instead of trusting edited
descriptors. Every decode refusal preserves both float output and float scratch;
success changes only the requested prefix. Names borrow original headers.
Callers retain valid aligned allocations, truthful extents, lifetime,
immutability, exclusive access and truthful overlap observations when bypassing
the native wrapper. This is synchronous publication, not a concurrent transaction
or a general memory-safety proof.

The artifact portion of M5 is implemented under these limits. Elephant/Mammoth
original checkpoints have not been downloaded, loaded or executed by these tests.
Full model tokenizers/config interpretation, architecture/resource qualification,
autodiff, optimizer/RNG/data-state resume and GPU execution remain later work.
No owner action, paid service or external model script was required.
