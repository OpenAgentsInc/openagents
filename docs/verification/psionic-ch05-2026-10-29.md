## Independent evidence and scope

The retained [fixture manifest](../../psionic/fixtures/text/ch05/manifest.json)
and [provenance](../../psionic/fixtures/text/ch05/provenance.json) identify the
original data, licenses, serving patch and source revisions. Owned Python
standard-library tooling verifies and packs the data without running downloaded
code. Its independent tokenizer oracle uses a priority queue rather than the
Coax implementation's linear scan; its Unicode oracle uses Python 3.15.1's
Unicode 17 tables. No model weights or upstream runtime were executed. Comparing
against the official runtime and testing full model execution are separate
qualification steps.

This profile specializes the pinned tagged text-only request and admits bounded
JSON objects and arrays with integer, string, boolean and null values. It
refuses floating/exponent numbers and integers over 4,300 digits. Resource
limits are explicit and never silently truncate. The caller retains ownership,
valid extents, exclusive access and an immutable admitted tokenizer table for
its lifetime. The implementation does not claim arbitrary chat-template or
multimodal support.
