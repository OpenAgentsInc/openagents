## Scope

This is a bounded teaching profile, not an implementation of the complete
Qwen3.5 architecture or a claim of Elephant/Mammoth execution. The caller
supplies the positional table, owns its intended unit rotations, and keeps
cache history consistent with the same weights, shape and positions. The
library verifies declared bounds and overlap observations, not pointer
provenance, concurrent access or the history's semantic identity. Its full
sequence path uses the same step implementation; the separately implemented
fixture oracle supplies the independent numerical comparison. Real upstream
intermediate tensors, hybrid recurrence, decision masks and full checkpoint
qualification remain future work.
