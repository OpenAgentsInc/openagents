# Chapter 106: differentiate any tensor program, 2026-10-30

**Environment:** macOS 26.4 arm64 (Apple M5 Max), coax0 0.24.0 built from this tree, Python 3.15.1.

**What landed**
- `psionic/lib/autodiff.coax` (`#authority`, profile autodiff-f32-v1): reverse mode over chapter 38's tensor IR.
  - Gradient mode: per-input `grad`, per-node `detach` and `custom`, and a forward-only switch. Unused inputs are reported, not zero-filled.
  - A static tape: forward steps, then backward steps in reverse node order. Value, staging and gradient lifetimes are placed first fit in an f32 value arena and an f64 gradient arena. A value is saved only while a backward rule reads it.
  - Forward steps run chapter 38's own command kernel (`tik_run`) with lowered metadata. Backward rules cover add and multiply with broadcasting, matmul, ReLU, sum over an axis, gather (scatter-add) and layer norm (recomputed in f64). Gradients land in the root storage through views and reshapes.
  - Registered operators (chapter 40) and custom derivatives come back to the caller as calls (`ad_run` / `ad_finish`), since Coax has no callbacks.
- `psionic/examples/autodiff-mlp.coax` and `psionic/fixtures/autodiff-mlp.out`: a 2-8-1 network on chapter 40's registered squared ReLU, with gradients checked against central differences and then trained by gradient descent.
- `psionic/tests/autodiff_oracle.py`: an independent rebuild of the example's output, using the standard library only. It plans the tape and arenas itself, emulates the f32 forward pass, and writes the network's f64 backward pass out by hand.
- The chapter, plus rows in SUMMARY, README, PLAN and `examples.json`. `autodiff` is added to `check.sh`'s Coax units.

**Results**
- The tape has 10 forward and 9 backward steps.
- Values take 193 floats in 12 blocks while training, 128 floats when forward only, and 234 if every value were kept. Gradients take 161 doubles in 13 blocks. Three values are saved for backward (nodes 8, 9, 13); `x @ W1` is not, because `x` needs no gradient.
- Gradient check, h = 1/64: the largest difference is 0.000286, on all 33 parameters.
- Training at learning rate 0.01: loss 10.76 at step 0, 0.045 at step 800.

**Equivalent mutants in `autodiff.coax`**
- `best+size>a.top` against `>=`: both keep the same maximum.
- `ti_compile(…, false)` against `true`: the reuse flag moves only the IR's own workspace bases, which the tape never reads. It places values in its own arena.

**Process notes**
- The first mutation run left 118 survivors in the file. To kill them:
  - dead code was removed: the max-tracking `items`, a redundant gradient-death update, and initializers nobody read;
  - placement moved into an `AdArena` that counts its blocks;
  - tests were added for dead values, saved operands, views with strides and offsets, metadata against `ti_lower`, bit-exact forward output against the IR running its own plan, registered-operator metadata over a strided second operand, kernel flags, non-finite custom results, and every refusal.
- Constant-folding forbids non-finite bit patterns at compile time, so the non-finite tests make infinities by arithmetic overflow.
