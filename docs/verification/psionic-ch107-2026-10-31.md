# Chapter 107 — transform functions, not just tensors

The [chapter](../../psionic/book/ch107-transform-functions-not-just-tensors.md)
and [native qualification](../../psionic/fixtures/function-native-qualification.json)
implement immutable graph-function composition over the permanent CPU tensor IR.
The profile supports grad/value-and-grad/Jacobian/JVP/VJP/HVP and shared/mapped
vmap through order two, with explicit storage and a nominal work ceiling.

Six authority roots are frozen at **704/704 killed, zero survivors**: layout 95,
linearize 279, budget 18, transforms 104, products 142, batch 66. Final native
builds each pass 16,113 checks in debug/release/ASan-UBSan. All result bytes
match the prior frozen independent reference exactly; its analytic calculations
were reused only after that comparison. 33points include 84 exact F32 primals,
5,328 formal derivative values (max error 1.36e-15), and 30 smooth finite-
difference points (max Jacobian 9.43368e-7/Hessian 2.24479e-6). Frozen tolerances
are retained in the receipt. Final changed-dependency debug/release examples
match the committed golden transcript.

Coverage includes shared-input matmul, broadcasts, strided views, reshape,
repeated gathers, layer norm, ReLU’s zero convention, tied flat bindings and
holes, product dualities, Hessian symmetry, mixed value/gradient VJPs, HVPs and
batched Hessians. Admission checks cover exact and one-past capacities, every
workspace, honest overlap refusal, nonfinite values/partials, unsupported
operations/order/device, late-row poison and whole-batch atomicity. Numerical
scratch may change on refusal; public output and spare tails may not.

The executed C/header identities and final source bindings are in the receipt.
Later test-only source edits did not alter the executed production bodies.
This is formal F64 calculus at F32 stored primals, not derivatives of literal
floating-point rounding. It is not arbitrary-procedure/device differentiation,
a compiler bounded-control proof, a real-time guarantee or a general ownership
proof. Chapter 111’s owned RK4 parameter recovery remains a separate consumer.

After rebasing, upstream changes to tensor-view injectivity, tensor-operation
admission/reductions and broadcast layout produced genuinely changed generated
C. The changed native program alone was rebuilt in all three modes: every
16,113-check run and every saved result byte still matches the frozen reference.
The receipt retains both native builds and rebinds the three changed dependency
identities. The independent mathematical oracle and unchanged root mutation
gates were not repeated.
