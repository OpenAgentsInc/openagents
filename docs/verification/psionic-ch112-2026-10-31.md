# Chapter 167: imitation before robotics scale

The first robotics chapter delivers an owned simulated imitation learner and a
bounded original NVIDIA SingleArm data exercise. Its
[chapter](../../psionic/book/ch167-imitation-before-robotics-scale.md),
[example](../../psionic/examples/imitation-before-robotics-scale.coax) and
[focused runner](../../psionic/tests/robotics/check.sh) keep those scopes explicit.
This is not GR00T inference, an Isaac Sim integration or a physical robot driver.

## Frozen owned experiment

Profile `robotics-cartesian-bc-f64-v1` uses two Cartesian axes in metres,
workspace `[-1,1]`, maximum velocity `0.5 m/s` per axis and a fixed `0.1 s`
tick. Observations divide target error by `0.25 m`; actions divide velocity by
`0.5 m/s`. The expert is clipped proportional velocity. The independently known
affine solution is normalized gain 0.5 and bias 0 on both axes.

Four whole episodes, IDs 0–3, provide eight expert steps each. Existing chapter 103
SGD fits each axis using 128 full-batch epochs, 32 rows, rate 1, no decay,
initialization seed 0 and shuffle seed 112. The two heads perform 256 updates.
The scales, recipe and evaluation episodes precede fitting. Evaluation uses
IDs 100–105, 96 ticks each, and success only when both final absolute axis errors
are at most 0.01 m. Teacher-forced velocity MSE and candidate-owned closed-loop
states are separate calculations.

| Policy | Teacher-forced velocity MSE | Successful episodes | Worst final axis error |
| --- | --- | --- | --- |
| Zero | 0.057325929036138298 | 0/6 | 2 m |
| Learned | 2.9478047861576636e-34 | 6/6 | 0.00047750247539857238 m |
| Expert | 0 | 6/6 | 0.00047750247539846136 m |
| Half X gain | 0.0024315831520581098 | 2/6 | 0.020276547153583624 m |
| Half Y gain | 0.0026106195930875745 | 2/6 | 0.020276547153583624 m |

The worst expert error independently follows `0.5 * 0.9^66 m`: thirty saturated
ticks followed by 66 proportional ticks. Separate half-gain policies show that
lower action MSE than zero does not establish rollout success. The simulation
has exact observations and declared dynamics; it has no contact, delays,
collisions, vision or physical actuator.

## Original NVIDIA data

The retained [fixture and attribution](../../psionic/fixtures/robotics/singlearm-panda-open-drawer/README.md)
pin NVIDIA PhysicalAI-Robotics-Manipulation-SingleArm revision
`73c00c18e7ca108e91846294b20a1d7cd5de9340`, subset `panda-open-drawer`, under
the source's CC BY 4.0 attribution. Retained originals are 5319-byte `info.json`,
47-byte `tasks.jsonl` and 28043-byte `episode_000000.parquet`.

Existing PyArrow 24.0.0, through an independent development oracle, verified
all 133 original rows and selected frames 0, 1, 2, 3, 132 directly from Parquet.
The inert JSON and independent C tables preserve all 170 selected F32 words:
five timestamps, 125 state values and 40 action values. The last selected frame
has a gap; this is not a contiguous five-action replay. Original Parquet SHA256:
`90f5658a7af7d9df68746ec0726c290f218b279790fb5ad5026519a0c9a69c89`.

The actual metadata and Parquet have 25 state and 8 action channels, despite the
dataset card's 81-state description for this task. The named delta-position and
gripper channels do not specify sufficient controller units/scaling/sign
semantics for execution. Those values are not sent to the owned simulator.
No image/depth/video path is qualified.

Coax reads the original metadata and bounded inert JSON with at most 8192 bytes
and 8 rows, restores F32 bits exactly, refuses duplicate semantic keys and wrong
profiles/dimensions, requires finite values within `[-1000,1000]`, increasing
frame IDs and agreement with `frame/30` within an inclusive `2^-16 s` tolerance.
The binary tolerance and next representable value are checked explicitly.
Every row is staged before any output publication. The reader validates claimed
source fields; the separate original-file comparison proves this particular
fixture's content. A digest string alone is not authentication of new data.

## Remaining robotics work

GR00T requires a qualified exact artifact/terms profile, its vision/language and
flow path, and a verified embodiment adapter. Observation timing, action chunks,
resets, recovery and richer closed-loop simulation remain later work. This
chapter's finite owned-controller success does not establish Panda transfer,
arbitrary manipulation, real-world success or a new supported NVIDIA model.
