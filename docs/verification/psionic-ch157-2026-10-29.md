# Chapter 157: thresholds from written costs, 2026-10-29

Verified on macOS 26.4 arm64 (Apple M5 Max) with Apple clang 21.0.0, Python
3.15.1 and coax0 0.24.0. No model weights, GPU, network or upstream code were
used.

`psionic/lib/threshold.coax` implements profile `cpu-f64-threshold-v1`:
- binary64, chapter 3's compensated accumulator for every sum;
- written cost tables (each mistake, asking a person, each second, each model
  call) for a voice interruption and a background classification;
- expected costs of answering no, yes or asking at a probability, and of
  escalating to Mammoth, whose evidence is right with probability ρ, by
  Bayes' rule;
- version 1 threshold records of at most four bands, each edge the first
  double where the old action stops being cheapest, after a 1/4096 scan;
- the synthetic set `threshold-sim-v1`, ρ measured on validation data,
  policies scored with 95 percent normal intervals and paired differences.

## What mutation testing changed

- **The first band is always no:** at p = 0 answering no costs nothing, so
  its explicit assignment was a mutant no check could kill, and was removed.
- **Edge search:** a fixed 64 halvings became halving until the bounds are
  adjacent, bracketing on the previous band's action. Checks now cover a band
  inside the scan's first two steps, a first edge below 1/4096, a band
  narrower than half its upper edge, a table whose only cost is a wrong yes,
  and a tampered edge one number too high.
- **Variance:** written as e·e, since (v − m)(v + m) sums to the same value.
- **Exact counts** on a hand-made record, and 1-item boundaries.

## Not claimed

- **Synthetic, calibrated probabilities** and a known form for Mammoth's
  evidence.
- **One validation and one confirmation draw,** normal intervals, no interval
  on ρ carried into the record.
- **Bands narrower than 1/4096** could be missed by the scan; the example
  checks the record against the expected costs at every confirmation
  probability.
- **Process:** checks were written alongside the code, not run against stubs
  first.
