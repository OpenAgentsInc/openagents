# Chapter 159: a Pylon checks itself before serving, 2026-10-30

**Environment**
- Library and checks: macOS 26.4 arm64 (Apple M5 Max), coax0 0.24.0, Python 3.15.1.
- Engine runs: coderos-4080 (NixOS, RTX 4080).
  - Pylon built from C generated on the Mac with the same compiler.
  - Elephant (`baselabs/elephant-1` revision `b3f8a934`) served by `psionic-serve --elephant-gpu`, started through the machine's GPU switch.
  - The toy engine is `psionic-serve --toy`.

**What landed**
- `psionic/lib/pylon/selfcheck.coax` (`#authority`):
  - the reference-set reader;
  - exact decimal-to-billionths conversion;
  - the answer reader, on the Coax Nostr modules' bounded JSON parser;
  - the comparison and the whole-set check;
  - the identity gate and the doctor's step order.
- `psionic/lib/pylon/run.coax`:
  - new options `--references`, `--identity-state`, `--declare-identity` and `--doctor`;
  - at start, the self-check and gate run before any relay traffic, and failure stops the Pylon with status 6;
  - the doctor is read-only and exits 0, or 10 plus the failing step;
  - the identity is recorded only after the check passes.
- `psionic/platform/pylon-host.c`: reading a whole named file, writing one through a temporary file and a rename, and the exit status.
- `psionic/fixtures/pylon/elephant-1.selfcheck`: six cases recorded from Elephant on the 4080. Asked twice, the engine gave identical answers.
- `psionic/fixtures/pylon/psionic-toy.selfcheck`: two cases from the toy engine.
- `psionic/tests/pylon/pylon_e2e.py`: passes the set and a fresh state file, and checks the self-check line and the recorded identity.
