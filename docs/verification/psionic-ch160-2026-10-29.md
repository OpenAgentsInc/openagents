# Chapter 160: how far apart may two honest answers be?, 2026-10-29

Verified on macOS 26.4 arm64 (Apple M5 Max) with coax0 0.24.0 and Python
3.15.1. No model weights, GPU, network or upstream code were used, and no
model was called: the backends are simulated.

`psionic/lib/distance.coax` implements profile `cpu-f64-distance-v1`:
answer-sim-v1 items and backends, the centred-log distance with a 10⁻⁶ floor,
comparisons and nearest-rank percentiles, a round's verdict, simulated
rounds, limits from honest rounds with a gap rule, and a live round whose
checked subset is drawn from the answers' digest and the checker's secret.
