# Chapter 218: read a bounded ONNX graph, 2026-10-30

**Environment:** macOS 26.4 arm64 (Apple M5 Max), coax0 built from this tree, Python 3.15.1. Fixtures were written by `onnx` 1.17.0 and numpy in a scratch virtual environment. No GPU or network.

**What landed**
- `psionic/lib/onnx.coax` (`#authority`), profile onnx-17-v1:
  - its own protobuf field scanner;
  - opset 17 of the default domain and IR versions 7 to 10;
  - seven operators (Gather, ReduceMean, Conv, Relu, Flatten, Gemm, Softmax), each with only the attribute values it implements;
  - float initializers held in the file, static shapes, and bounds of 16 nodes, 32 values, rank 4, 4,096 elements a tensor and 1 MiB a file;
  - anonymous weights named from the nodes that use them (`/conv/Conv` → `conv.weight`);
  - refusals with a reason and, where there is one, a node;
  - a CPU run in binary32, with Softmax in binary64.
- `psionic/tests/onnx_fixtures.py`: writes the two models, 20 refusal files, and a case table of 123 files into `psionic/fixtures/onnx/`. With `--reference` it checks the main models with `onnx.checker` and ReferenceEvaluator.
- `psionic/examples/onnx-read.coax` and `psionic/fixtures/onnx-read.out`.
- `psionic/tests/onnx_oracle.py`: an independent standard-library reader and binary32-emulating evaluator.

**Mutation history**
- **First run, 351 survivors.** Added the case table: each refusal from its own onnx-written file, and admitted models checked against ReferenceEvaluator outputs.
- **Second run, 165 survivors.** Rewrote the reader with single validating scans and sentinel checks, then added hand-built wire tests for:
  - initializers field by field;
  - declarations and dimensions;
  - every attribute name, type, operator and value;
  - names at the 64-byte limit;
  - model and graph fields;
  - running at the bounds.
- **Third run, 17 survivors.** These led to:
  - the case `conv_full_width`, without a bias and with a batch larger than its channel count;
  - the refusals `conv_tall` and `conv_nine_attributes`, with the oracle given the eight-attribute limit;
  - a float_data value followed by a packed run;
  - a shape before its element type;
  - an unknown INTS attribute;
  - an arena too small at run time.
  - Separately, the element count now bounds each dimension against the remaining budget, so the product can't wrap. The per-dimension clamp in the initializer became redundant and was removed.
  - The test pixel helper's last SplitMix64 step was dropped. It only changes bits below the 1/32 grid.
- **Fourth run, 1 survivor:** Softmax's running maximum, `v>top` against `v>=top`. On a tie the mutant replaces the maximum with an equal value, so no input tells them apart.

**Not run:** the full `check.sh`, at the owner's request. `onnx` is added to its Coax units.
