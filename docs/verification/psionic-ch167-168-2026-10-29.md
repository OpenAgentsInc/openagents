# Chapters 167 and 168: arithmetic from ReLU, and a gate-graph compiler, 2026-10-29

Verified on Linux 6.18.49 x86_64 (coderos-4080) with GCC 15.2.0, Python
3.13.15 and coax0 0.24.0. No model weights, GPU, network or upstream code were
used.

`psionic/lib/relu-arith.coax` is the gated layer `x + O((Vx) ⊙ ReLU(Gx))`:
- binary64, or binary32 with every operation rounded in unit order;
- at most 64 residual slots and 128 units;
- refuses weights and inputs past 2⁵³, NaN and infinities.

Its gadgets are product, ReLU, step, equality, select and copy, exact for
integer inputs within ±2²⁶ in binary64.

`psionic/lib/gate-graph.coax` admits graphs of inputs, constants, linear nodes
and those gates:
- up to 128 nodes, 16 inputs and 16 outputs;
- a select's condition must be a step or an equality.

Its integer evaluator refuses the first node whose value leaves ±2²⁶. Its
compiler places linear nodes into the forms that gates read, puts each gate one
layer after its deepest operand, and reuses a residual slot from the layer of
its last reader. It emits binary64 weights for up to 32 layers.

## What mutation testing changed

The first runs left 44 and 88 survivors. They were fixed by changing code and
checks:
- **Gadget layers sized exactly:** each gadget's test layer now has exactly
  its units, so a misplaced unit fails.
- **Equality as five explicit units,** instead of a loop that flipped signs.
- **Observable code** in place of choices with no observable effect:
  - a maximum written as "update if greater";
  - "never read" written as −1;
  - loops over node 0, which is always an input;
  - a scan one layer past the last.
- **Constants pinned:** a constant became its own base node fixed to slot 0
  and never cleared. The last two survivors showed that nothing tested a
  constant read by an early gate before a later layer still needed slot 0.

## Not claimed

- **Exact profile, not chapter 6's block.** RMSNorm and SiLU can't be exact,
  so the block keeps chapter 6's residual stream and gated feed-forward layer
  without normalization, with ReLU gating, in binary64.
- **No attention sublayer.** Attention memory joins in chapter 170, and the
  compiler's own differential harness is chapter 169.
- **Process:** checks were written alongside the code, not run against stubs
  first.
