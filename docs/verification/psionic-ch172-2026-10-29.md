# Chapter 231: from hard-max to softmax, 2026-10-29

Verified on Linux 6.18.49 x86_64 (coderos-4080) with GCC 15.2.0, Python
3.13.15 and coax0 0.23.0. No model weights, GPU, network or upstream code were
used.

`psionic/lib/soft-memory.coax` reads memory by a softmax over chapter 225's
parabola score, recency-weighted (score × (T + 1) + t), at sharpness β. In the
format under test it rounds:
- each score,
- each scaled logit,
- each probability,
- each stored value.

Exponentials and sums are binary64 with compensated addition. bfloat16 is
binary32 rounded to nearest-even at bit 16. A read is exact when the weighted
value, rounded half up, equals the hard-max answer. The chapter proves that
β ≥ ln(4V) keeps every read exact for values in [−V, V] at any trace length.
It then measures the trace lengths at which binary32 and bfloat16 rounding
break two adversarial streams.
