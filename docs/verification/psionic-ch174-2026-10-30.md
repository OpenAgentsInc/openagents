**What the example shows**
- Training: `count` and `sum` at n = 1 to 4, 220 machine rows (880 tokens). A copy of `count 4` with one token changed, and its digest redone, fails replay and is not admitted.
- Held out: 14 traces, admitted as `heldout` rows.
- Linear student, 10,000 epochs (converged): loss 0.3044, 424 of 440 tokens right from true states. It is never exact, because it can't write `brif`'s target.
- Gated student, 10,000 epochs: loss 0.0002, 440 of 440 tokens right from true states. It is exact on 5 of 16 runs, and wrong on `count` at n = 16 and 32 and on `sum` at n = 32.
- Gated student, 100,000 epochs (converged): loss 0. It is exact on all 8 `count` and `sum` runs, up to 8 times the training length (1,036 and 1,308 tokens). It fails `stride` at its first `sub`, because every training `sub` subtracts 1. It fails `squares` at its first `mul`, which training never shows.
- Table student, 10,000 epochs (converged): loss 0.0097, 432 of 440 tokens. It is not exact even on the training programs, and it fails at the first value it never saw.

**Mutation history**
- **First run, 50 survivors.** These led to:
  - a test pinning every family's instructions and arguments: most survivors were arguments of instructions that ignore them;
  - a small program where the second stack value is not the local, for the rules written by hand;
  - an output check that tells an out row's x from the row before it, and a run of 65 outputs into exactly 64 slots;
  - boundary cases at one example, budget 1 and `n = 0`;
  - training that refuses an out-of-range code by counting each code's examples, instead of a separate check;
  - the step written as 2 g over the summed squared norms, since the example count cancelled out of the rate;
  - test examples built in one loop, so no literal is left that can't matter.
