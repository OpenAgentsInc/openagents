**Findings while building**
- **Wires name outputs only.** Chapter 227's compiler reuses residual slots, so a block's input slots may hold other values by its last layer. The first linker read inputs from their slots, and the link-versus-chain tests failed. A module now exports any input it passes on; the step module exports `a`.
- **Slot 0 is refused for both modules.** Both read slot 0 as the constant 1. A first module that wrote it would change the second module's constant inside the link only. The copy checks every layer of both modules.
- **A test bug:** one test reused an output buffer from an earlier check, which hid a wrong answer. It now has its own buffer.

**Mutation history:**
- **First run, 28 survivors.** They were closed by restructuring the slot map onto a base offset, computing the weaker label as `x+y-max(x,y)`, removing redundant checks, a golden digest vector computed with Python's `hashlib`, pre-filled output buffers, and negative tests for the helpers.
- **Second run, 6 survivors,** all in a test helper's junk-fill of the conformance cases. Once neither case used op 0, the fill was unobservable. It was removed, and both cases now use a nonzero op, so dropping any assignment changes a case.
- **Third run:** see the table above.

**Not run:** the full `check.sh`, at the owner's request. `weight-module` is added to its Coax units.
