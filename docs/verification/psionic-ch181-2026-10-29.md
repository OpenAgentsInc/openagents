# Chapter 240: environments with checkers, 2026-10-29

Verified on macOS 26.4 arm64 (Apple M5 Max) with coax0 0.24.0 and Python
3.15.1. This run used no model weights, GPU, network or upstream code, and
called no model: the agent is simulated.

`psionic/lib/env.coax` implements profile `cpu-int-env-v1`:
- task-sim-v1 tasks and their reference solutions;
- three checkers;
- admission: the checker fails on empty work, passes the reference and fails a
  near miss;
- the environment digest;
- agent-sim-v1 attempts;
- rollouts whose digest chains each attempt and verdict, and replay.

| Native harness | None yet. `check.sh` runs only the Coax checks. The full `check.sh` was not run, at the owner's request. |

Results:
- **Admission.** All 40 environments with exact checkers are admitted. On the
  first task, three variants are refused:
  - the `anything` checker, because empty work passes;
  - the `length only` checker, because a near miss passes;
  - a wrong reference, because it fails its own checker.
- **Rollouts.**
  - The agent with skill 0.35 solves 32 of 40 environments, 18 on the first
    attempt, using 78 attempts in all.
  - The agent with skill 0.75 solves 39 of 40, 29 on the first attempt,
    using 53 attempts.
- **Replay.** All 80 rollouts replay exactly. A rollout record with a changed
  attempt count is refused, and so is a replay against a changed
  environment.
