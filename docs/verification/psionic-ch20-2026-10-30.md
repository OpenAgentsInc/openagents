# Psionic chapter 25: the API fans out

This record qualifies the opt-in loopback `psionic-fleet` adapter. It does
not publish or replace the production decision API. Keys are fresh random
throwaway buyer identities, never production keys. No money or real-owner
identity is involved. Remote model identity remains a signed provider claim,
not model attestation.

Implementation:

- `psionic/lib/fleet/policy.coax`: bounded routing/reply/fallback gates.
- `psionic/lib/fleet/protocol.coax`: correlation and asked-answer validation,
  exact serializer-decimal arithmetic, request projection.
- `psionic/lib/fleet/service.coax`: free service selection and complete local
  HTTP framing, using the existing checked JSON/HTTP/beacon units.
- `psionic/lib/fleet/run.coax`: native Coax wiring with existing relay,
  NIP-42, BIP-340, NIP-44, entropy and sockets; no replacement crypto.
- `psionic/platform/fleet-build.sh`: native plain/sanitized targets.
- `psionic/platform/fleet-host.c`: I/O-only host, independently qualified in
  `psionic-fleet-host-2026-10-30.md`, source `ac46409f46` on main.

Compiler used: `/tmp/oct30-pylon-demo/coax/bin/coax`, SHA256
`df4d78ef4ddc8f788cb4a87da31d538a2ecf174af14085a5f34ab1d868a80fb0`.
The shared checkout's older Oct28 compiler was not used for qualification.
