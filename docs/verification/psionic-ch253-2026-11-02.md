## Implemented scope

`weight-edit-f64-v1` is an immutable small-model CPU interface, not an
original-model-sized loader or a model-quality/deployment gate. It binds
profile, complete named tensor layout and all value bits by SHA-256, checks
each expected old value and returns a whole owned result. Its native tests
include nonfinite encodings that Coax's compile-time evaluator refuses to
construct, and subnormal/signed-zero handling. The immutable input and
value-returning result avoid an in-place alias/publication protocol.

The experiment-specific library converts head/unit removals into sparse
edits. Those persistent edits are compared against chapter 119's causal
activation interventions. Source-linked examples and exact transcripts
teach the interface and the saved five-seed experiments.

## Artifacts and experiments

The [matrix protocol](../../psionic/fixtures/weight-space/protocol.md) was
written before matrix measurement; model prompts and budgets were fixed in
the runner before its first call, with this protocol note assembled while
the initial batch was running. This is an exploratory working-tree study,
not an independently preregistered trial. The author knew chapter 119's
seed-119 result. Model requests were fresh/stateless and could not read files,
call tools or inspect labels/evaluator code.

- Ten 664-parameter artifacts were prepared once in Coax: five seeds with
  hint weight 0.75, five no-hint controls, 300 AdamW steps each. Saved weights
  define identity. Native seed 119 differed from the old compile-time fixture
  by at most `3.022749225922716e-08`; cross-build training equality is not claimed.
- A 180-row matrix replays unchanged/no-op models, both head removals, a
  development-selected head/unit ablation, three deterministic 32-position
  random patches and permutations for 20 model instances: the ten trained
  models, five initialized models and five erased readouts.
- The separately declared ten-step fine-tuning comparison costs 150 sequence
  forward/backward passes/model and changes 624 scalars. Exhaustive ablation
  uses 231 development sequence forwards/model and changes 0, 8 or 32 scalars.
  These are different compute budgets and objectives. No hyperparameter retries.
- Original GPT-OSS-20b revision
  `6cee5e81ee83917806bbde320786a8fb61efebee`, existing original MXFP4/BF16
  cache, was served by our Metal Responses path on private loopback 8794.
  Existing model/runtime authentication ran on startup. The public local test
  credential is not a secret. The server was stopped after the 32-call batch.
- Calls were greedy, low reasoning, no tools; 512 output-token ceiling except
  selected decoder-weight prompts, which reserve 256. There were **25
  completed, five incomplete and two `invalid_model_header` errors**. The
  latter are Responses output-parser errors, not evidence of corrupted weights.
- Reported usage totals **14,482 input tokens and 6,352 output tokens**, of
  which 6,057 were reported reasoning tokens. Failed server responses expose
  no usage. These totals exclude the preliminary READY smoke call and model
  startup. No failed experiment trial was retried.
- The initial CSV print did not quote comma-containing unit-pair proposals.
  Its exact stdout is retained as `llm.raw.out`. The corrected CSV is an
  **offline Coax replay** of the same 32 responses; request bytes must match
  the saved originals. It did not call the model again.

## Conclusions and limits

The old seed's informed head-1 edit raises correct held-out answers 12→14
of 15, retaining six of six clean answers. Across five fresh seeds, fixed
head-1 removal meets the frozen descriptive criterion on two and harms other
models. Development-selected ablation meets it on one; random patches on none
of fifteen attempts. None of this is a multi-task qualification result.

The descriptive criterion has false positives: some initialized models have
lower NLL but still zero correct answers. No-hint models also fail the proposed
healthy-control role when evaluated with unseen hint tokens. Those findings
are preserved. Neither criterion nor proposed model edit controls serving.

The local LLM produces no usable repairs on the four faulty complete-network
cases under its token limit. Partial decoder weights produce two correctness
gains and one regression; attention observations produce three gains and seven
regressions. Paired permutations expose a non-invariant choice in one seed.
Counts are dependent within seeds; small samples, omitted tensors, rounding,
one proposer and finite budgets prevent broad capability conclusions.

Chapters 254–255 are explicitly unimplemented design drafts. The original
Qwen loop repair, learned-model circuit transplantation, rank-one removal,
norm-matched random patches, broad seed/task statistics and production
promotion remain further work. No owner action is required by this change.
