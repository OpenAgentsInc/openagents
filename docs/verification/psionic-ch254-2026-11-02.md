its five named tensors reuse chapter 253's immutable identity/edit contract.
A separate postfix admission front end feeds chapter 229's existing gated
compiler. New checks precede implementation; both admission authorities have
zero surviving entry-source mutants. Experimental learner/task/recorder
modules confer no quality or deployment authority.

The full protocol and inert data live in
[`psionic/fixtures/construction`](../../psionic/fixtures/construction/protocol.md).
The chapter records all 19 task calls, 25 baseline artifacts and 24 grid
rows, plus timing and startup failures. Sixteen proposals are admitted;
all twelve admitted arithmetic proposals pass 1936 held-out rows per task,
and the four admitted control proposals reach every held-out start by a
shortest route. All match elementary native/hand references. Native Coax
execution is cheaper in the measured loops.

Three-seed same-architecture AdamW baselines approximate rather than solve
exact arithmetic; absolute-value MAE is .00680–.00878. Control succeeds from
18/13/25 of 25 starts, with 17/12/23 shortest paths. A planted M64
conditional passes every development row and fails 16 held-out rows.
The all-zero controller fails every held-out start. Frozen map-A Q-learning
fails transfer; Q-learning separately trained on each test map matches the
reference after thousands of transitions. The latter has different experience.

The controller receives oracle shortest-path neighbor distances. This
qualifies action selection on those features, not learned navigation,
general games, PPO superiority or recovery after a map change. Compiler
program synthesis is distinct from direct fixed-architecture weight writing.
Original language-model editing remains chapter 255's draft.
