# Chapter 50: original MXFP4 decoding, 2026-10-29

Verified on Darwin 25.4.0 arm64 with Apple clang 21.0.0
(`clang-2100.1.1.101`), Python 3.15.1 and coax0 0.22.0, compiler SHA-256
`c5acf492faaef7ea8450245c44b454e69b208f83d9594e874be4d06eb3d3ae1a`.
The starting repository revision was `0cbc392c8a`.

The first gpt-oss chapter implements the separate
`gpt-oss-mxfp4-f32-v1` decoding profile. It receives bounded original-format
packed byte and scale windows; it does not parse or authenticate checkpoint
files. Each row contains complete 32-value groups, with at most 1,048,576
output values and scale bytes restricted to 0–252. Every admitted value has
an exact finite binary32 representation, including signed zero and subnormals.
Scales 253–255 refuse the entire window before any output write. This
conservative scale restriction is not a claim about all original model data.

Sources were cloned to `~/work/projects/repos/gpt-oss` and
`~/work/projects/repos/harmony`, then read at revisions
`5681a6b6552635e7b29cde94a61ca6a7aee90ebd` and
`abd677f7ac962629c808197caa1feb9e3e95d2b0` respectively. No downloaded
setup, conversion or inference scripts were executed. The pinned gpt-oss
weight loader specifies the magnitude table, low/high nibble interleave,
32-value groups and scale exponent. Harmony was read to preserve the boundary
between this format chapter and the later conversation-format implementation.

Reproduce the focused gate from the repository root:

```shell
coax/build.sh
psionic/tests/check_mxfp4.sh
python3 -I psionic/tests/book.py --coax coax/bin/coax
```

`COAX=/absolute/path/to/coax` selects an already built compiler. The complete
book gate checks exact source-linked listings, local links and runnable
transcripts. The main `psionic/check.sh` includes this decoder in its normal
Coax and native gates; the entire multi-chapter suite was not rerun for this
standalone addition.

The byte fixtures are synthetic original-format data, not captured model
weights. Complete U8 tensor inventory/pair binding, checkpoint hashes and scale
coverage, model-specific arithmetic, routing, Harmony and complete gpt-oss
execution remain unqualified. This record establishes no GPU or Linux backend
support and no quality claim for a newly quantized model.
