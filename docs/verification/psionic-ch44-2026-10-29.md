`COAX=/absolute/path/to/coax` selects an existing trusted compiler. The focused
gate checks source-data/fixture drift, debug/release checks, native plain and
sanitized builds, the example and authority mutation. Admission and message
mutation roots separately cover every new authority unit and their imported
shared code. `psionic/check.sh` integrates the same roots and native harness.
The entire earlier multi-chapter mutation suite was not rerun for this addition.

The C adapter observes addresses only. Table identity must be admitted once;
callers retain valid aligned allocations, truthful extents, immutable table and
input bytes, lifetimes and exclusive writable access. The profile's budgets
are 64 messages, 16,384 IDs, 65,536 logical decoded bytes, 64-byte ASCII
identifiers, 256-byte headers, 1,024-byte pieces and a 16,777,216
sum-of-squared-piece budget.

This is an owned Unicode-17 text-profile qualification, not complete
upstream-runtime parity for every Unicode version or optional Harmony feature.
It excludes nicknames, arbitrary channels, constrained/header extensions,
multimodal payloads, incremental stream decoding, history-filter policy and
tool execution. A parsed call supplies no execution authority. Original-weight
generation and sampling are chapter 64 gates; tool integration is chapter 77.
