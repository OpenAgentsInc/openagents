# Chapter 89 supplement — the original V4.1 text tokenizer on CPU

2026-10-30. Profile: `deepseek-front-v41-text-v1`. This finishes the original
text-tokenizer integration for chapter 89's bounded recipe and stream profile.
It does not implement the complete upstream recipe or execute the model.

## Original data and exact text contract

The tokenizer comes from DeepSeek-V4.1-Flash-1017 revision
`1bae0e1088993b9b82de08f59de5be5a34e42170`. Its original JSON is already retained
by chapter 94 as `engram-tokenizer.json.gz`, with uncompressed SHA-256
`c90dfa01249db1be4245780a052ede752e1361c612ac6d08e2bdada7d599476b`.
The new packed table contains 129,280 vocabulary entries and 127,741 ranked
merges in 3,978,447 bytes. Its complete identity is in
[front-v41-source.json](../../psionic/fixtures/deepseek/front-v41-source.json).
Native execution admits that table with Coax `pw_digest`; a changed byte fails.

The original has no normalization. Three ordered isolated splits separate
number triples, exact source CJK ranges, then the source's word/punctuation/
whitespace alternatives. Unmatched gaps survive. BPE follows original ranks
and leftmost ties within each piece. Typed controls bind exactly BOS/EOS
0/1, system 128799, user 128803, assistant 128804, think/end-think 128821/128822
and DSML 128825. Every other added ID refuses. Marker spellings inside ordinary
text never become controls. Adjacent plain fragments rejoin even across UTF-8
scalar boundaries; actual controls split independent encodings.

## The Unicode mismatch found and fixed

Using the current regex library's default Unicode properties was incorrect:
its newer database treats U+0558 as a letter while the original tokenizer's
regex engine does not. Python's built-in Unicode 15.1 database was also too old
for the original: Unicode-16 additions U+16100 and U+1C89 are letters there.

The implementation now pins primary Unicode **16.0.0** data, including
`UnicodeData.txt` and `PropList.txt`, and generates the precise property ranges
used by Coax. The independent regex oracle uses those same primary-source
classes explicitly, rather than inheriting its library's newer database.
Both source files and their hashes/URLs are retained. No downloaded source
script or model implementation was executed.

An opt-in independent reference check compares the original Rust tokenizer's
complete pre-tokenizer with the explicit-data regex equations on
`"a" + scalar + scalar + "b"` for **all 1,112,064 Unicode scalars**. Every probe
agrees. This is an exhaustive scalar-probe check, not exhaustive string testing.
The native Coax lookup independently matches the primary-source property digest
at **all 1,114,112 code points**, including zero flags for surrogate positions.
Retained text regressions distinguish Unicode-16 and Unicode-17 additions.

## Ownership, scope and evidence reuse

Callers must bind admitted immutable table/source identities, valid typed
allocations/extents, live borrowed strings and exclusive disjoint outputs.
Checked text/encoding/unit entry points stage public output completely. Private
scratch can change on failure. Exported low-level span probes require a
validated UTF-8 slice, an in-range scalar start and successful unmodified layout;
the checked text entry points establish those preconditions.

The R1 adapter, existing bounded recipe and parser remain their original
contracts. Their unchanged earlier checks are retained in the
[initial chapter-89 record](psionic-ch57-2026-10-29.md); this new native gate also
exercises the recipe and parser through original V4.1 token IDs. Full upstream
schemas/tool declarations, namespaces, call-ID sorting, numeric reasoning effort,
mid-conversation systems, assistant prefixes and media remain unimplemented by
that bounded API. There is no checkpoint-output or serving-performance claim.

Focused gate constituents ran separately while developing the change. The final
Coax implementation and owned check inputs did not change when Unicode property
data was corrected; earlier passing Coax/mutation results were reused after
byte-identity checks. Native and external data comparisons ran on the corrected

for publication. Executed C/header snapshots, logs and source/compiler/binary
