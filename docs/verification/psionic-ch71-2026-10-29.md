# Chapter 104: gradients as a program, 2026-10-29

Verified on macOS 26.4 arm64 (Apple M5 Max) with Apple clang 21.0.0, Python
3.15.1 and coax0 0.24.0. No model weights, GPU, network or upstream code were
used.

`psionic/lib/tape.coax` implements profile `cpu-f64-tape-v1`:
- programs of 1 to 4,096 nodes over 13 operations: parameter, constant, add,
  sub, mul, div, neg, square, exp, log, tanh, sigmoid, softplus;
- operands name earlier nodes, so programs are acyclic and run in order;
- 0 to 4,096 parameter slots;
- every value, adjoint and gradient within ±10¹⁰⁰, and `exp` arguments up to
  230.

The forward pass saves every value and publishes only on success. The
backward pass reads only saved values. It accumulates adjoints over fan-out
and gradients over every node that reads a slot, and adds into caller
gradients, which the caller zeroes.

`tp_tabular`, `tp_gradient` and `tp_train` express chapter 103's models as
programs and train them with chapter 103's loop. Chapter 103's training
admission moved into `tb_admit_train`, which both trainers call. That
refactor kept chapter 103's 55 checks, and its mutation count went from 921
to 923, all killed.

## What mutation testing changed

The first full run left 4 survivors, all fixed in code or checks:
- **A saved-value check** that another check covered by accident. A new check
  gives an out-of-domain value to a node nothing reads.
- **A sum index initialized to 0** and always reassigned before use. It is
  now declared without a value.
- **A capacity test written `n < 0`** for a count that is either −1 or at
  least 2. It is now `n == −1`.

Guards that would have been equivalent mutants were designed out:
- division by zero and overflow are caught by the domain bound, not by
  separate tests;
- `log` and `exp` return a value outside the domain when they have no
  result. Coax's evaluator traps on `log` of a non-positive number, so the
  guard is needed.

## Not claimed

- **Scalar nodes only.** No tensors, second derivatives or custom rules.
- **A teaching tape.** It is not tuned for speed; a program is rebuilt for
  every batch.
- **Process:** checks were written alongside the code, not run against stubs
  first.
