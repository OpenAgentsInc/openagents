# Psionic M0: learning one number

Verified 2026-10-28 on an Apple arm64 LP64 host with Apple clang
21.0.0 (`clang-2100.1.1.101`) and a freshly bootstrapped coax0 0.16.0.
Compiler source baseline: OpenAgents `493c31a1df7f2a1f5689e6c6b300c501dc436fcd`.
The sources and runner in this change define the tested implementation.

## Commands and outcomes

From the repository root:

```sh
coax/build.sh
psionic/check.sh
```

Both completed with exit status zero. The compiler bootstrap emitted an
existing unused-parameter warning in `coax/src/emit_c.cpp`; no compiler source
was changed. The new native library/adapter/test builds use `-Wall -Wextra
-Werror`, with generated-code unused-function/parameter warnings suppressed.

| Gate | Observed result |
| --- | --- |
| Authored Coax checks | 13 checks pass: 634 total finite cases, including admission endpoints and failure publication. |
| Authority mutation | 65 generated mutants, 65 killed, zero survivors. No equivalent exemptions. |
| Closed-form native oracle | Every step count 1–64 compared with `w(k) = 2 - 2*(3/8)^k` and the corresponding loss curve. |
| Independent quadratic oracle | 1,280 additional training runs over sample counts 1–16, five initial weights, and step counts 1–16; every trace value compared with independently computed quadratic coefficients. |
| Native representation and storage | Real infinities/NaNs, signed zero/subnormal and range boundaries; malformed counts, short capacities, six alias arrangements, adjacent spans, shared read-only input, and early/later update refusal. |
| Native build modes | Debug `-O0` and release `-O2`, each plain and with ASan/UBSan; all four runs pass. |
| Book structure | Two programs in the closed inventory, three exact source-linked listings, valid local links. |

All native builds use `-ffp-contract=off -fno-fast-math`. Sanitized builds
instrument the emitted Coax C, native overlap adapter, and test harness.
LeakSanitizer is disabled because it is unsupported on this Mac; this report
makes no leak-detector claim. ASan/UBSan remain enabled and fatal on errors.

Five manual defect controls also exercised the book checker without changing
working files: an empty inventory, an omitted program, a changed source
listing, an unexpected process exit status, and changed output. Each was
rejected. These controls used temporary mocked inputs to the checker; normal
book runs compiled and executed the actual programs.


The exact-arithmetic weight error after sixteen steps is approximately
`3.0586534904841756e-7`. Adding the chapter's conservative per-update rounding
allowance through the geometric recurrence gives a weight error bound below
`6.874e-7`, within the fixed `1e-6` tolerance. The corresponding prediction
bound including multiply rounding is below `2.301e-6`, within `3e-6`.
Final training loss must be at most `1e-11`. These tolerances were specified
independently of the observed results.

The Coax print transcript uses fewer significant digits than the native
harness; its exact fixture is retained separately in
[`psionic/fixtures/learn-number.out`](../../psionic/fixtures/learn-number.out).

## Scope

This is a synchronous scalar CPU learning/inference example with caller-owned
storage, fixed-rate SGD, bounded samples/steps/numbers, and atomic publication
of the loss trace. Native callers remain responsible for actual allocation
validity and storage lifetime. The overlap adapter observes whole declared
spans; it cannot validate arbitrary pointer ownership.

The finite checks, mutation sites, numerical cases, and sanitizer runs do not
prove arbitrary-input correctness or general memory safety. No timing or
allocation benchmark, physical-phone run, Linux/Windows target, tensor system,
autodiff, model import, GPU dispatch, serving, or training-quality qualification
was performed. The tiny held-out example checks the same synthetic linear
relation; it is not evidence of real-world model quality. No owner action or
paid compute was required.
