# Self-range request admission

2026-11-08. Baseline `31a30eb2dd`. Partial progress on
[#13038](https://github.com/OpenAgentsInc/openagents/issues/13038).
The containing commit and [source hashes](source-hashes.txt) identify the work.

False Life could grant Temporary Hit Points to another creature. Source p.129
says its range is Self and grants the caster those points. The new structural
request gate refuses a different primary creature before spending an action,
slot or Quickened Sorcery Points, rolling dice, writing events or replacing
concentration. Ordinary and Quickened casts on the caster still spend normally
and grant 2d4 + 4 Temporary Hit Points.

The compact source projection now preserves the canonical range form for all
339 entries; its source check verifies every field against the pinned catalog.
Classification uses that field, not a legacy record's zero-foot range. For
example, Water Walk's source range is a distance, despite its old zero-foot
executable field. Generating/checking the index remains independent of the
engine, so it regenerated while the new engine regression still failed.

Under Range (p.105), Self can also identify an effect's origin. The gate leaves
originating areas/directions intact, preserves Divine Smite's existing hit-rider
target (p.125), and excludes later helper actions such as Produce Flame's hurl
(p.156). Existing hit/slot/target checks still apply. A malformed primary target
is distinct from p.106's invalid-creature-type outcome: Hold Person on an Undead
still spends its used slot without affecting it.

The [regression failed before the fix](red.txt). It checks refusal snapshots and
successful ordinary/Quickened casts on the caster. A 16-row truth table covers
request shape combinations; metadata fixtures cover Self, non-Self, originating
effects, helper ID zero and out-of-range/house IDs. The mutation scope is the
new authority, with no equivalent-mutant or execution-coverage exemptions;
it does not qualify all unchanged legacy engine procedures. Earlier unchanged
selection/access/target gates remain at their recorded commits and were not rerun.

Experimental passed under its unchanged compiler limit at 32,646,270 of
33,554,432 value slots (97%). Its selected checks do not claim full-entry
execution coverage or browser-rendering qualification.

The new native CAST-SELF witness checks an eligible, prepared False Life request
against the wrong primary creature. Effect capacity, zone capacity and parked
Polymorph remain the three failures. This does not complete components/costs,
casting workflows, all range/visibility rules, explicit upcast/multiple-target
selection or every source effect. #13038 remains open.
