# Valley Lab: next three geometry phases

Three concrete phases extend the original-rock star into bounded groups,
adjacent mixed cuts and a deterministic repeated-rock field. The batch began
from `879510ac7c`; product logic, native packers and browser drivers are Coax.
The Python file is explicitly an independent oracle (Firm reason 2), imports
no project code, and recomputes topology and distance from emitted bytes.

## 1. Bounded multiple-interior reduction

`aethyr/render/geometry/grid-parent.coax` supports a canonical positively
projected 4×4-cell nonplanar grid. Four nonadjacent interior stars collapse
to existing vertices. The stars share no triangles, so the maximum of their
upward-rounded error bounds, including child error, bounds the entire union.
Every outer edge and segment stays exact. Exact topology, coordinates,
source construction, transformed axes, malformed geometry and atomic refusal
are covered. All 113 authority root mutants die; no equivalents are declared.
The unchanged star primitive reuses its 90-killed receipt from `1ff1535068`.

This class has 25→21 vertices and 32→24 triangles. It is not an arbitrary
edge-collapse implementation or a qualification of ill-conditioned imported
geometry. Unsupported geometry keeps its source representation.

## 2. Adjacent original-rock groups

`verse/valley/rock-grid.coax` extracts two neighboring groups from cube face
+X. Native tests match all source triangles to the unchanged original rock
and check the same five boundary vertices / four seam segments at all cuts.
Each group has 700→556 encoded bytes and 1,384→1,096 logical resident bytes.
The parent uses VGP1, served as 1,112 lowercase hex bytes over real HTTP.
All three original generator hashes stay pinned and unchanged.

| Profile | Whole-rock source | One parent | Both parents |
| --- | ---: | ---: | ---: |
| 8 | 768 | 760 | 752 |
| 16 | 3,072 | 3,064 | 3,056 |
| 32 | 12,288 | 12,280 | 12,272 |

Native pages and source proof files are produced by:

```
coax/web/tool.sh aethyr/tools/valley-grid-pages.coax PAGE_DIRECTORY PROOF_DIRECTORY
python3 aethyr/tests/valley_grid_oracle.py PROOF_DIRECTORY PAGE_DIRECTORY apps/openagents-web/assets/valley/field-v1.json
```

The independent oracle checks oriented edge multiplicity, Euler disk topology,
all 16 external segments, exact boundary words, original hashes, the four
mixed seam combinations and the minimally upward L1 certificate. It samples
1,440 source and 1,080 parent points per group against independent f64
point-to-triangle distances, in both directions. Samples supplement the
analytic barycentric certificate, rather than defining the bound.

## 3. Deterministic six-rock field

`verse/valley/field.coax` records layout version 1 / seed 12609, six placement
cells, yaw and exact binary scales 1 / ½. A native Coax writer pins all 30
f32 words in `assets/valley/field-v1.json`; the browser compares every word.
Per-instance projection uses transformed bounds and scaled geometric error,
with 10 µm to cover the qualified field's transform rounding. The oracle
also checks affine-distance and modeled f32 rounding enclosures for each
instance, group and supported profile.

Six rocks retain one source asset and share two page identities. At profile
16, source/mixed/coarse counts are 18,432 / 18,384 / 18,336. Two successful
HTTP requests supply all twelve coarse group uses, occupying 2,192 logical
resident bytes. With 1,096 bytes, six groups use their full source triangles.
Field `L` supports profiles 8 and 16; entry from 32 selects 16. Profile changes
advance the page epoch, so old arrivals cannot replace the new profile.

This workload exceeded the old 64,000 submitted-vertex limit. The declaration
and physical buffer were increased together: 80,000 submitted vertices,
81,920 physical HUD vertices, and a 7 MB CPU arena. Actual paged frames use
69,066 submitted vertices on desktop and 66,834 on phone; arena bytes are
6,483,512. Geometry remains within 16,384 vertices / 65,536 indices. Native
checks cover the desktop and both high-DPR teaching screens, source/mixed/
coarse cuts, and both supported field profiles.

## Limits

The field uses CPU-transformed indexed copies on the original scene/HUD path.
It does not qualify hardware instancing, a GPU page registry, shared-renderer
upload/retirement, occlusion, indirect submission or world-cell streaming.
Logical page residency does not imply reduced fixed physical allocation;
original source assets remain retained, and page bytes are not whole-asset
download savings. This is an orbitable lab field, not the completed walkable
valley tile. Saved walkthroughs, source import and book draft exits remain open.
