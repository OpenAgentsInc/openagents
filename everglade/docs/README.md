# Everglade design docs

Specifications for Everglade systems that aren't yet chapters of
[Building Everglade](../book/README.md).

- [Golemancy: a profession for commanding golems](golemancy-profession-spec.md):
  the name is decided; the rest is a design proposal: golems you command from
  the workbench in your house, in the world and, through your OpenAgents
  account, outside it.
- [Housewright: gathering materials and building houses](housewright-profession-spec.md):
  gather branches, withies, reeds, clay and stone, make primitive tools, and
  build from a branch lean-to to a stone cottage on a plot in the city
  clearing, with a four-branch talent tree.
- [Everglade for desktop: Mac, Linux and Windows](desktop-app-spec.md): a
  proposal for the native app that plays Everglade and holds the Golemancers'
  Workshop, a standalone local world where each golem is a Claude agent on
  your own Claude Code login.
