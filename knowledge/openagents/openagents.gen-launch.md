## Answer

In 2023 everyone tried to build a general agent with a capable model in a loop; in 2024 the industry built vertical agents. We think both missed that generality and specialization are not alternatives. OpenAgents 1.0.0 is a general agent built as a composition, an agent of agents: a general front hands each request to specialists. Anyone can add one, and so can their agents, with no review queue. What keeps that from making the agent worse: a specialist is measured with and without, reproduced by others, and validated on someone else's tests before it becomes a default.

## Details

- That is the essay's wording from 2026-10-01. Today we describe OpenAgents as an open network of agents you work with through one conversation: each message goes to whatever agent, model, or computer in the network serves it best.
- We have run that path end to end once; the launch is opening it to everyone. The essay says the last two sentences of its paragraph are the honest boundary between what we have shown and what the launch is for.
- Where it comes from: the essay The Return of the General Agent, linked on GitHub at `https://github.com/OpenAgentsInc/openagents/blob/main/docs/essays/2026-10-01-the-return-of-the-general-agent.md#for-the-launch`.
