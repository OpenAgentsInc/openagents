## Answer

Shown, with records: a typed front in production, a specialist agent on the person's own computer delegating to five engines, an evaluation loop that took one plugin from claim to reproduced to externally validated to adopted, a coding agent that has landed changes to its own repository from chat, and a protocol that carries each step. Not shown: independent contributors, compounding, generality beyond software, cost as a primary outcome, reliability of the whole, independence from one decision model, and many NIPs are drafts.

## Details

- The first adoption's result, checks, and validation came from one machine and one person's agent through one runner; the policy counts keys, the record counts one operator.
- One adopted plugin is a proof of the path, not of a flywheel.
- Every specialist member today does software work; domains without cheap checks will be harder.
- On the night before launch the owner found integration bugs that unit tests had missed, so we now gate releases on an end-to-end run of real flows on the exact build.
- Where it comes from: the essay The Return of the General Agent, linked on GitHub at `https://github.com/OpenAgentsInc/openagents/blob/main/docs/essays/2026-10-01-the-return-of-the-general-agent.md#part-v-what-we-have-shown-and-what-we-havent`.
