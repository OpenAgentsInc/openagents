## Answer

The essay lists open questions: how large and how independent a second test set must be; how to pin a baseline that includes unpinnable hosted weights; how to limit evaluator collusion, Sybil reproduction, and cartels; how to separate development from confirmation to avoid the winner's curse; which changes should reopen an adopted claim; how deep a judgment stays useful in composition; and how evidence should scale with stakes.

## Details

- Others: reach (how to describe capabilities to the judgment that picks them, possibly the cheapest gain available), which baseline a shared claim is stated against, marginal deltas, marginal authority, independence of reruns, cost, uncertainty and power, grader quality, process-level deltas, safety of admission, and how compute and capability interact.
- The last is network evidence: does the flywheel turn? Its measure should be reported even when it is zero.
