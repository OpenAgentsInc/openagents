## Answer

The capability flywheel is the loop in which people add capabilities, tests produce claims, others reproduce them, tests the author did not write validate them, and adoption hands them to every agent, which then takes on harder tasks that reveal the next missing capability. It is the mechanism by which a network of contributors could improve an agent faster than one team can. It is a hypothesis to measure, not a result.

## Details

- The measure is not participant counts and not raw passes: it is marginal externally validated utility on a declared task distribution per adopted contribution, with regressions, cost, latency, and authority reported beside it.
- Raw new passes are reported too, but they are not the target.
- Where it comes from: the essay Test-Time Capabilities, linked on GitHub at `https://github.com/OpenAgentsInc/openagents/blob/main/docs/essays/2026-09-29-test-time-capabilities.md#11-the-capability-flywheel`.
