Phive profile implemented
  Common header: Phive\0, LE BOM, kind2 compound or kind0 shape; dynamic u8
  section capacity at0x0b, parallel u32 offset/size arrays at0x0c. Actual
  compounds use capacity160. The terminal nonempty offset is whole-file size.
  HKT profile is exactly SDKV20250200; other profiles refuse.
  Mesh root: type7 at+0x18, inverse quantization at+0x50, relative section
  array at+0x88. Geometry sections are0x40 bytes: primitive view+8,
  byte vertex view+16, signed int32 section origins+32. Decode position as
  (uint16_code + signed_origin) * float_inverse_scale. Vertex views can
  contain2 trailing padding bytes; only indexed six-byte XYZ records decode.
  Primitive ABCD emits ABC and, when C!=D, ACD. Raw winding survives.
  Compound root type9: relative instances pointer+0x38, count+0x40.
  Each64-byte instance stores quaternion+0, translation+16, scale+32,
  relative shape pointer+48. Nested transforms apply scale, quaternion,
  translation at each level; nonuniform scale is not collapsed or normalized.
  Convex/type0 and box/type5 retain float3 vertices at relative view+0x38,
  four-byte faces at+0x48, byte vertex-index list at+0x50. Convex faces are
  fan-triangulated. These are collision cores; original margin/solver behavior
  is not reconstructed. Type3 cylinder remains explicitly unsupported.

KCG1 little-endian layout
  Header64 bytes:magic KCG1 at0,version1 at4,triangle count8,nx12,nz16,
  float cell20,west24,south28,cell-table offset32,reference offset36,
  reference count40,triangle offset44,total bytes48,max-cell-count52,
  reserved zero56/60. Each cell is u32 first-reference,count. References are
  u32 original triangle ids. Triangles are nine float32 values (ABC XYZ).
  Whole-stream identity/admission and retained lifetime belong to the private
  pack owner; runtime query preconditions require that admitted immutable view.

Runtime helpers and limits
  metaverse/ocarina/kokiri-grid.coax: kokiri_encoded_floor returns highest local
  triangle at/below caller's height, exact slopes and original triangle id.
  Outside the index is an explicit miss, never an edge-clamped invented floor.
  Use current feet plus allowed step height; querying above all roofs changes
  which layer is selected. Caller owns slope/step/grounded movement policy.
  kokiri_encoded_lateral returns corrected feet plus tested/contact counters.
  It uses capsule-segment/triangle closest points and three bounded local
  depenetration passes on faces steeper than55degrees. Y is preserved.
  This is fixed-step depenetration, not continuous CCD or original Havok
  parity. Camera ceilings, triggers, original body filters, convex margins,
  the one cylinder and arbitrary high-speed wall crossing remain separate.
