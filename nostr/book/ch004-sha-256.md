# 4. SHA-256

> **Status: partly implemented.** The code and its checks exist in Coax; the
> teaching text, worked trace and runnable example are not written yet. The
> registry lists the source files.

SHA-256 is the first primitive Nostr needs: an event ID is the SHA-256 of its
serialization, and BIP-340, HMAC, HKDF and NIP-44 all build on it. This
chapter builds the compression function, the padding and a streaming
interface, then checks them against the published vectors.

Part II, Hashes and MACs. Result: Streaming SHA-256 over caller-owned state,
checked against every NIST CAVS ShortMsg and LongMsg vector, with split-stream
and padding-boundary checks, plus BIP-340 tagged hashes.

## What this chapter teaches

- The eight working variables, the 64 round constants and the message
  schedule.
- Padding: a `1` bit, zeros, and the 64-bit length, with the 55-byte and
  56-byte boundary cases.
- Streaming: `update` in any split gives the same digest as one call.
- Tagged hashes for BIP-340: `SHA256(SHA256(tag) || SHA256(tag) || msg)` for
  `BIP0340/challenge`, `BIP0340/aux` and `BIP0340/nonce`.
- A worked trace: the digest of `abc`, `ba7816bf…f20015ad`.
