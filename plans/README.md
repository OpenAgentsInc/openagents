## How these plans were made

- A standard-depth audit: four read-only subagents covered security,
  correctness, tests and performance, and tech debt, dependencies, tooling
  and docs. The advisor then read the cited code for every finding that
  became a plan.
- Every plan is written for an executor that has seen nothing but the plan
  and the repository.
- This repository's rules apply to every plan: work in your own worktree
  from `origin/main`, never on a branch and never in the main checkout; add
  no new Python, shell or TypeScript tool without a `Firm reason:` header;
  never edit an existing migration.

## Findings considered and rejected

- SQL injection in the API: not a finding. Queries use `PQexecParams`; the
  plain `PQexec` calls pass constant strings.
- Cookie flags: not a finding. Every `Set-Cookie` carries `HttpOnly` and
  `Secure`, with `SameSite=Strict` or `Lax`.
- `strcpy` in the API: not a finding. Every site copies a short constant
  into a buffer sized for it. Request bodies are copied into
  `malloc(body_len + 3)`.
- The committed Breez API key: by design, recorded in `AGENTS.md`.
- Non-Coax tools without a `Firm reason:` header: already tracked in
  `coax/tools-port.txt`, and `tools-check` enforces the rule for new files.
- Everglade zones copying shared features, and large units near compile
  limits: already tracked in issues #13079 to #13088 and #13094.
- No after-landing check on `main`: already tracked in issue #13102.
- No test gate on API deploys: a documented owner decision of 2026-11-01
  (`coax/web/api/deploy.sh:8-12`). The index above lists what would make a
  fast gate possible.
- Release checks that report and do not stop a release: a documented owner
  decision of 2026-11-02 (`coax/web/release.sh:19-24`).
- Indexes for the time-window queries on maker tips and payouts: not worth
  doing until tip volume grows.
- Stale `.gitignore` and `.gitattributes` lines, and a Mac-only
  `compile_flags.txt`: noise only.
- Splitting the largest, most-edited Coax game modules: the size and churn
  are measured, but the conflict cost is not. Investigate before planning.
