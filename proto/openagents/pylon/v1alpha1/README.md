# Pylon mesh projections

Alpha projections of the existing NIP-PYLON3201 receipt.v2,1985 NIP32 labels
and30201 pool.v2. Published JSON and original signed event bytes remain
authoritative; these messages do not replace versions or imply verification.
The first Coax profile is free accepted remote decision jobs only, with
explicit trusted input lists and independently recomputed pool totals.
Paid receipt fields are represented for compatibility but not implemented
by that profile. See NIP-PYLON's Coax free mesh implementation profile.

The separate original GPT-OSS20B text profile uses existing signed Nostr events
and the existing NIP-90 `5050` request, `6050` result and `7000` feedback kinds.
Its beacon declares `nip90-5050`. The public-text subset is specified in
`nips/openagents/NIP-PYLON.md`; it introduces no replacement event envelope or
SystemOne message version. Original event bytes remain authoritative.
