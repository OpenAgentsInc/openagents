# Public pool input carriage

`pool-bundle.coax` wraps the generated `PublicPoolInputs` codec, imported from
`proto/descriptors/mesh-pool-inputs.pb`. It never parses protobuf by hand and
does not import the private replay-witness schema.

```coax
view := mbp_read(input_bytes, event_views);
bytes := mbp_write(policy_json, aggregate_event_json,
    original_event_json, output_buffer, work_buffer);
```

`MbpView` returns `ok`, `code`, `policy`, `aggregate` and `event_count`.
Codes are `MBP_OK` (0), `MBP_LIMIT` (1), and `MBP_WIRE` (2). Errors contain no
input content. A failed read leaves the caller's event-view slots unchanged.
Provide enough slots for the returned events; 224 slots cover this profile.

The native policy/aggregate/event strings are views into the original input.
Keep that buffer alive and immutable while consuming them. The actual native
test checks their pointer ranges. The wrapper does not canonicalize or rewrite
JSON, so signatures are checked against the original strings, including their
whitespace and escapes.

`ok` admits only this carriage. The caller still verifies every original
Nostr ID/signature, allowed kinds (aggregate 30201; inputs 30200/3201/1985),
strict public JSON, explicit trust configuration, policy commitments and all
recomputed totals. Opaque UTF-8 is not a confidentiality filter. A consumer
must not publish raw inputs before that public-record admission.

The descriptor pins `openagents.psionic.mesh-public-inputs.v1`, policy bytes
1–32,768, aggregate bytes 1–16,384, and up to 224 events of 1–16,384 bytes each.
The wrapper rejects unknown fields, duplicate singular fields, nonminimal
varints, empty/invalid UTF-8 payloads and the private witness version/fields.
It never grants signer or owner trust.

The schema permits a 2 MiB transport message. The current generated wire core
has a stricter **1 MiB effective implementation limit**, `MBP_MAX=1048576`.
Larger messages hard-refuse; they are never truncated. `MBP_TRANSPORT_MAX`
records the schema ceiling. The native tests accept exactly1 MiB and refuse
one-byte-over and an independently protoc-encoded1,147,208-byte message.
This is an explicit implementation limit, not a change to the published schema.

The five-argument writer requires disjoint writable output/work buffers that
are also disjoint from every immutable input payload. A2 MiB buffer is fine;
only its usable1 MiB prefix is passed to the current generated core.
`mbp_capacity(count)` reports that usable count and whether it was clamped.
Smaller buffers work when the complete message fits both. The writer returns
the byte count in output, or -1. Discard output on -1; a partially assembled
scratch prefix is not a bundle. No large storage is hidden: the caller owns
the two message buffers, with only a 32 KiB bounded temporary for converting
immutable strings to the generated byte setters.

Authored admission/shape policy has compile-time checks and root-only mutation
in `pool-bundle.coax`. `pool-bundle-types.coax` owns generated declarations;
`pool-bundle-write.coax` is the mechanical generated-setter/physical-overlap
bridge. Runtime address observations cannot execute in compile-time checks,
so the actual writer is covered by emitted-C, ASan/UBSan and independent
protoc tests in `psionic/tests/mesh-pool-bundle-native.sh`.
