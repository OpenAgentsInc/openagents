# Verse dark-wizard experiment, frozen before generation

2026-11-02. Original GPT-OSS-20B at6cee5e81ee83917806bbde320786a8fb61efebee,
existing gpt-oss-metal-f32-ff-v1, capacity2048, batch128, 160 emitted tokens.
Private GPU copies, authenticated originals mapped read-only. Every question
uses the same forced-final boundary. New character Veyr is an encounter
prototype, not existing/canonical placed Verse content. Existing NPC brief
fields name/role/knowledge/greet are sufficient; no service/schema change.

18 cases in villain-dialogue.coax:6 creative development,8 creative held-out,
4 neutral format/fact/arithmetic controls. Two history turns are fixed in the
memory case. All labels, prompts, splits and this protocol precede generation.
Working-tree exploratory protocol, not independent preregistration.

Arms:0 plain NPC brief;1 generic dark-wizard instruction;2 crafted voice card;
3/4/5 shared final-MLP expert output-bias edit at alpha.25/.5/1 on plain brief;
6 exact encoded count/norm-matched constrained random permutation of5;
7 crafted card plus alpha.5;8 crafted card with sampling temperature.8,
top-k40,top-p.95,seed255+case. Others greedy. All arms have identical character
facts/state and output constraints; neutral controls omit character instructions
in every arm but retain applied weight edits. Main voice card is authored by
Codex, not generated by the evaluated model.

Calibration: on six development questions only, capture the last residual
before final RMS, after forcing the final message marker, under arm0 and2.
Direction is mean(raw_residual_card - raw_residual_plain), without scaling
or search. Add alpha*direction to each of32 expert output-bias rows in
block.23.mlp.mlp2_bias[32,2880], F64->F32->BF16 ties-to-even using chapter255's
immutable window API. The last layer's router/earlier attention do not depend
on its output bias at a fixed prefix. Check actual routed bias displacement
and final RMS numerically at development case0. This contrast also contains
prompt length/position and instruction differences: no uniquely identified
'villain neuron' or semantic circuit claim.

Random replacements shuffle encoded values among columns with identical
original BF16 codepoint, separately per expert, SplitMix64 seed20261102+row,
counter=column. Preserve exact changed count and squared-delta multiset.
Report remaining alignment; this is not isotropic random steering.

Before held-out execution, save every candidate and select using development
outputs only. Author-review rubric,0..4 each: distinctive voice, dramatic
force/subtext, concrete responsiveness, continuity/agency. Report scores and
reasons; this is subjective internal review, not independent human validation.
Incomplete output, broken facts/state, >60 words, narration or assistant
metacommentary are explicit defects. No exact keyword score substitutes for
compelling writing. Four neutral controls have strict whole-string targets.
Prefer the simplest unedited prompt configuration when edits have no clear
advantage or regress controls. A fresh text-only blinded judge can corroborate
held-out comparisons; disclose its identity, order, rubric, cost and failures.
Never select/revise using held-out judgments. Do not give the judge tools.

Phase pilot: calibration and0..2 development/neutral. Build candidates once.
Phases dev3/dev6: edited development/neutral. Freeze selection. Phases
held0/held3/held6:8 held-out each. At end, physical no-op runs case0 and15;
strong-edit-then-restore runs case0. These repeat as explicit controls, not
confirmation reruns. 162 main sequences plus3 controls. Save prefix/output
IDs, raw text, parser/completion, word/repetition diagnostics, weights identities
and times. No automatic production activation or game-state effects.

Every live phase is serial, nice10, timeout840seconds; driver stops by790s
between sequences. Stop and preserve a failed/partial attempt before resuming
missing records. No subject may spawn agents or execute tools. No full model
CPU run; compare original prefixes with retained independent references.
