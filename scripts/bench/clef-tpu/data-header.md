## Method

- **Stack.** JAX 0.11.1 with its bundled libtpu, SGL-JAX at commit
  `673f2fce` (pins the JAX version), Python 3.12 venv on the stock TPU VM
  images (`v2-alpha-tpuv6e`, `v2-alpha-tpuv5-lite`, `v2-alpha-tpuv5`).
- **Matmul** (`bench_matmul.py`): `[tokens, K] @ [K, N]` at every projection
  shape of Clef-Flash (hidden 4096, FFN 12288, GDN 16/32 heads) and Clef 27B
  (hidden 5120, FFN 17408, GDN 16/48 heads), tokens 128…32k, one chip.
  bf16; int8 W8A8 with static scales (the MXU ceiling); int8 W8A8 with
  dynamic per-token activation quantization (what Qwix/AQT PTQ emits:
  absmax, round, int8 dot into int32, rescale); int8 weight-only; fp8 e4m3
  (no fp8 MXU on v5e/v6e/v5p, so it is emulated and shown for completeness).
  Median of three timed loops after warmup.
- **Gated DeltaNet** (`bench_gdn.py`): the tpu-inference `gdn/v3` fused
  Conv1D + chunked gated-delta-rule Pallas kernel as vendored in SGL-JAX
  (`fused_chunk_parallel`), the SGL-JAX pure-JAX chunked version, and the
  token-by-token `lax.scan` reference (conv + SiLU with the same weights,
  f32 state). Error is mean |Δ| / mean |ref| and max |Δ| of the layer output.
  Two gate regimes: `fast` (the SGL-JAX test fixture: state forgets within
  ~10 tokens) and `long` (dt_bias −8…−4: state remembers ~10³ tokens, like
  trained heads), which is the one that tests state precision.
  `bench_gdn_state.py` carries the state between chunks of a long prompt
  through a bf16 or f32 state pool, as a chunked-prefill server does.
- **Attention** (`bench_attn.py`): causal, head_dim 256, GQA 16/4 (Flash)
  and 24/4 (27B), splash attention (MQA form per KV head, blocks 256–1024),
  Pallas flash attention (KV repeated), XLA. TFLOPS counts the causal half.
- **Full-model prefill** (`bench_prefill.py`): SGL-JAX's offline `Engine`
  with the real scheduler (chunked prefill 8,192, page 64, radix cache off),
  `Cloudflare/clef-flash` and `Cloudflare/clef` configs (identical to
  `Qwen/Qwen3.5-9B` / `-27B`), dummy weights for throughput (same shapes and
  FLOPs; real-weight loads are timed separately), B prompts of L random
  tokens, `max_new_tokens=1`. Each shape runs three times; the first
  includes any compile, the best of the other two is the steady state.
  Tokens/s counts prompt tokens. Throughput includes the scheduler, the
  vision-free text path and the LM head on the last token of each prompt
  (Clef skips that; our head is smaller).
- **Cost** per million prompt tokens = catalog $/chip-hour × chips ÷
  (tokens/s × 3,600) × 10⁶, fully busy. Spot and on-demand prices are from
  the Cloud Billing catalog for the VM's region (`prices.json`). At 50 %
  utilization, double them. References: our spot H100 $0.11/M, spot A100
  $0.072/M, Jev $0.042/M.
- **Several jobs per host.** On v6e-8 / v5e-8 / v5p-8 hosts we pin
  independent jobs to chip subsets (`pin.sh`: `TPU_VISIBLE_CHIPS`,
  `TPU_CHIPS_PER_PROCESS_BOUNDS`), so one host measures a 4-chip, two 1-chip
  and a kernel job at once.
