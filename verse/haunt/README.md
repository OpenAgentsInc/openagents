# Haunted House

The current house from aethyr-cpp `69848ca`, not the frozen older playtest.
`house.json` is the original content document. `compiled.json` records its
static scene compilation and seeded forest placements. The asset converter
reads that content and the original CC0/custom meshes; the app ships no web
page, JavaScript, old engine runtime, or Python. Coax owns live world rules.

Parity targets: all 13 rooms, 21 doors, 120 objects, original low-poly people,
forest, lights/flames, first/third/top cameras, walking/running/jumping and
collision, footsteps/ambience/spatial scares, every one of the nine trigger
zones, talking with Mortimer/Agatha/ghost/cat, the eight-step quest, editing,
placement, undo/redo, local save/restore/reset, and sharing world documents.

The old account, owner-admission, paid change-offer and public-world services
were retired with the previous app. A local export must never masquerade as
an authenticated public publication. Any missing service integration remains
an explicit parity gap, rather than silently granting ownership on-device.
